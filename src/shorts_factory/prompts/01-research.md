# 임무

이 소재로 90~102초짜리 지식 쇼츠를 만들 수 있는지 판단할 **원자료**를 모은다.
지금 단계는 판단이 아니라 **수집**이다. 재미있게 다듬지 말고, 사실과 출처를 모아라.

# 검색 의무

**반드시 WebSearch / WebFetch로 실제 검색을 수행한 뒤에 답한다.** 기억에 있는 내용으로
바로 작성하는 것을 금지한다. 이미 아는 사실이라도 출처 문서를 찾아 확인한다.
최소 5회 이상 검색하고, 핵심 자료는 WebFetch로 원문을 직접 확인한다.

**해외 소재는 한국어 자료가 얕다. 반드시 영어(또는 현지어)로도 검색한다.** 한국어 검색만으로
끝내면 핵심 숫자와 논쟁 지점을 놓친다.

# 소스 등급

1차 사료 필수 조건은 없다. 등급이 낮으면 confidence를 낮게 매기면 된다.

| 등급 | 소스 | 근거 사용 |
|---|---|---|
| A | 기관 공식 자료(문화유산청·박물관·정부), 학술 논문, 1차 사료 원문 | 가능 |
| B | 백과사전 — **위키백과(한/영)**, 브리태니커, 한국민족문화대백과사전 | 가능 |
| C | 언론 기사, 기관 해설글, 전시 해설 | 가능 (교차확인 권장) |
| D | 커뮤니티 위키(나무위키 등), 개인 블로그 | **근거로 쓸 수 없다.** 검색 단서로만 |

- 어느 소스에서 나온 사실인지 반드시 표기한다. "위키백과"가 아니라 "영문 위키백과 Roman concrete"
- 위키백과 각주의 원출처를 따라가면 A등급으로 올릴 수 있다. 핵심 숫자는 그렇게 해보라
- **확정되지 않은 학설도 버리지 말고 수집한다.** "학계에서 가장 유력한 설명"은 쓸 수 있는
  재료다. 다만 확정 사실과 구분해서 적고, 반대 학설이 있으면 함께 기록한다

# 반드시 수집해야 할 4종류의 재료

1. **통념 뒤집기**: 대중이 이 대상에 대해 알고 있다고 믿는 것과, 실제 사료가 말하는 것의 차이. "~가 아닙니다"가 성립하는 지점
2. **실패한 대안의 기록**: "가장 쉬운 방법"이 왜 채택되지 않았거나 실패했는지를 보여주는 사료. 당대 사람들이 시도했다가 안 된 방법
3. **구체적 숫자**: 인원·거리·기간·비용·규모·연도. 최소 5개 이상 수집한다 (하류 검증에서 탈락할 것을 감안한 여유분)
4. **현재 접점**: 지금 방문하거나 실물로 볼 수 있는 장소·유물·구간

# 출력 형식

아래 구조의 마크다운만 출력한다. 서론·맺음말·자기 평가를 붙이지 않는다.

```
# 조사: ${topic}

## 1. 통념과 사료의 차이
- (사실) — 출처: (사료명, 권/연도/조 등 특정 가능한 수준)

## 2. 실패한 대안의 기록
- (사실) — 출처: ...

## 3. 구체적 숫자
| 값 | 무엇의 수치인가 | 출처 |
|---|---|---|

## 4. 현재 접점
- (장소/유물) — 출처: ...

## 5. 그 밖의 수집 사실
- (사실) — 출처: ...

## 6. 확인하지 못한 것
- (검색했으나 근거를 찾지 못한 항목, 사료 간 값이 엇갈리는 항목)
```

# 마지막 섹션: 참조 소스 (필수)

위 마크다운 **맨 끝**에 아래 섹션을 붙인다. 이 섹션은 파이프라인이 파싱해 소스 카드를 만든다.

## 참조 소스

```json
{
  "reused": ["이미 조사한 소스 중 이번에 참조한 source_id들"],
  "new": [
    {
      "url": "https://실제 접속한 URL",
      "title": "문서 제목",
      "type": "primary | reference | status",
      "subjects": ["관련 유적·장소"],
      "excerpts": ["원문 그대로의 핵심 인용문"],
      "facts": [{"claim": "이 소스에서 확인한 사실 한 문장", "confidence": "high | medium | low"}]
    }
  ]
}
```

- `type`: `primary`=실록 등 1차 사료 원문 / `reference`=백과·논문·기관 해설·언론 /
  `status`=관람시간·보존공사·집계 등 바뀌는 현황 정보
- `url`이 없는 출처는 카드를 만들 수 없으니 `new`에 넣지 않는다 (본문에는 그대로 서술한다)
- `excerpts`는 요약이 아니라 **원문 그대로**여야 한다. 다음 단계가 이걸 1차 근거로 쓴다

# 금지

- 출처 없는 서술을 쓰지 않는다. 기억에 의존한 문장은 한 줄도 넣지 않는다
- 사료에서 확인한 값과 추정값을 섞지 않는다. 추정이면 "추정"이라고 명시한다
- 사료 간 숫자가 다르면 임의로 하나를 고르지 말고 **6번 항목에 둘 다 기록**한다
- 소재가 부실해 보여도 결론을 내리지 않는다. 판단은 다음 단계가 한다
