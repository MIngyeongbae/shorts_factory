# 무엇을 고치는가

**위반 문장이 가리키는 것을 없앤다.** 검사기는 낱말·구조를 기계로 재므로, 사유가 지목한 것을 지우거나 바꾸면 통과한다.

1. **카메라 워크 단어가 걸렸으면 그 낱말을 버린다.** 움직이는 것은 피사체다. 예를 들어 건설 현장에서 `crane`이 걸렸으면 그 기계를 `a tall lifting rig`·`a boom hoist`처럼 **워크 단어가 아닌 이름**으로 부르거나, 문장에서 그 기계를 빼고 **피사체가 어떻게 변하는지**만 남긴다 — "steel sections rise tier by tier until the mast is seated on top". 워크는 씬 계약의 `camera`가 이미 정했으니 당신이 적을 것이 아니다.
2. **라벨이 안 맞으면 계약의 글자를 따옴표째 그대로** 옮긴다. 한 글자도 바꾸지 않는다.
3. **있어야 할 단락이 없으면 채우고, 없어야 할 단락이 있으면 뺀다.** 씬 계약에 `action`이 없으면 `action_prompt` 키를 넣지 않는다 — 없던 씬에 사건을 지어내면 계약에 없는 동작이 화면에 뜬다. `info`가 없으면 `red_prompt`를 넣지 않는다.
4. **STAGING을 되풀이했으면 그 문장을 지운다.** 무대 문구는 코드가 어휘에서 넣는다.
5. **계측 표시가 새어 나갔으면** 빨강·화살표·라벨·글자 언급을 `red_prompt`로만 몰고 나머지 단락에서 지운다.
6. **너무 길다고 걸렸으면 줄인다.** 라벨이 둘이라 치수선을 두 벌 서술하면 상한을 넘기기 쉽다 — 공통 부분을 한 번만 쓰고("two pure red dimension annotations in the same drafting style, each with …"), 두 번째는 다른 점만 적는다. **라벨 문자열은 줄이지 않는다** — 그것만은 따옴표째 그대로다.
7. **절 이름을 값 안에 넣지 않는다.** `SUBJECT:`·`ACTION:`·`CAMERA:`·`RED:` 같은 머리말은 코드가 골격에 붙인다. 값은 그 절의 **내용만**이다 — 머리말을 넣으면 화면에 두 번 들어가고 길이도 그만큼 먹는다.

# 절대 지키는 것

- **연출을 바꾸지 않는다.** 구도(framing)·카메라 워크(camera)·무대(staging)는 씬 계약이 정했고 골격은 코드가 붙인다.
- **피사체를 바꾸지 않는다.** 씬 계약의 `subject`가 무엇을 그릴지 정했다. 당신은 **그것을 어떻게 서술했는가**만 다시 쓴다.
- **카메라 워크 단어를 쓰지 않는다** — 어느 단락에도. 금지어 전부: ${forbidden_words}. 굴절형도 같다.
- **영어·ASCII만.** 곡선 따옴표·전각 문자·이모지를 쓰지 않는다.
- **길이 제한을 지킨다.** `subject_prompt` ${subject_min}~${subject_max}자 · `action_prompt` ${action_min}~${action_max}자 · `camera_target` ${target_min}~${target_max}자 · `red_prompt` ${red_min}~${red_max}자.

# 출력 스키마

정확히 이 구조의 JSON 객체 **하나만** 출력한다.

{
  "scenes": [
    {
      "scene_id": 14,
      "subject_prompt": "...",
      "action_prompt": "...",
      "camera_target": "...",
      "red_prompt": "..."
    }
  ]
}

- `scenes`에는 **위에 주어진 씬만** 넣는다. 하나도 빠뜨리지 않는다
- `scene_id`·`subject_prompt`·`camera_target`은 **반드시** 채운다
- `action_prompt`는 그 씬에 ACTION이 주어졌을 때만 넣는다. 없었으면 **키를 넣지 않는다**
- `red_prompt`는 그 씬에 RED가 주어졌을 때만 넣는다. 없었으면 **키를 넣지 않는다**
- `subject_prompt_shot2`·`mj_subject`는 위에 주어졌을 때만 같은 이름으로 넣는다

# 출력 형식

JSON 객체 하나만 출력한다. 코드펜스(```), 설명, 머리말, 맺음말을 붙이지 않는다. 첫 글자는 `{`, 마지막 글자는 `}`여야 한다.
