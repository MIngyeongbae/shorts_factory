# 00. 개요

## 목표

주제(한 줄) 입력 → 완성된 쇼츠 mp4 출력까지 전 과정을 자동화한다.

## 소재 도메인

**제한이 없다** (ADR-0033 §1). 판별 기준은 하나다 — **그림이 설명의 일부를 질 수 있는가.**

이 채널의 정의가 "90초 안에 글과 그림으로 함께 설명한다"이므로(ADR-0022) 기준은 도메인이
아니라 **매체 적합성**이다. 국가·시대 제한은 원래 없다 (ADR-0016). 자세한 판별은 스펙 06.

다국어판(일본 쇼츠 등)은 이 리포지터리를 넓혀서 담지 않는다 — 분량·시그니처가 언어별
실측에서 나오므로 분기하거나 로케일 팩을 얹는다.

## 산출물 정의

- 포맷: 9:16 세로, 1080×1920, 30fps, h264 + aac
- 길이: `specs/schema/script-rules.json`의 `limits.total_seconds` (쇼츠 한도 내 최대 밀도)
- 구성: AI 생성 배경 영상 + 느린 카메라 모션 + 디졸브 전환 + 번인 자막 + 대형 강조 텍스트 + TTS 내레이션 + SFX/BGM

## 성공 기준 (MVP)

1. 주제 1개 입력 시 사람 개입 없이 mp4 1개 생성 완료
2. 대본이 `01-script-template.md`의 **결과 제약**(분량·수미상관) 검증을 통과.
   구조는 소재마다 다르므로 검증하지 않는다 (ADR-0033)
3. 모든 씬이 `specs/schema/scene.schema.json` 검증을 통과
4. 자막 타이밍과 TTS 오디오 싱크 오차 ±200ms 이내
5. 생성 실패 씬은 재시도 후에도 실패 시 파이프라인 전체를 멈추지 않고 리포트에 기록

## 비목표 (MVP에서 제외)

- 유튜브 업로드 자동화
- 썸네일 생성
- 다국어 버전
- BGM 자동 작곡 (라이브러리 선곡으로 대체)
