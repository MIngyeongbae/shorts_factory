# 00. 개요

## 목표

주제(한 줄) 입력 → 완성된 쇼츠 mp4 출력까지 전 과정을 자동화한다.

## 산출물 정의

- 포맷: 9:16 세로, 1080×1920, 30fps, h264 + aac
- 길이: 90~100초 (쇼츠 한도 내 최대 밀도)
- 구성: AI 생성 배경 영상 + 느린 카메라 모션 + 디졸브 전환 + 번인 자막 + 대형 강조 텍스트 + TTS 내레이션 + SFX/BGM

## 성공 기준 (MVP)

1. 주제 1개 입력 시 사람 개입 없이 mp4 1개 생성 완료
2. 대본이 `01-script-template.md`의 7단 구조 검증을 통과
3. 모든 씬이 `02-beat-schema.md` 스키마 검증을 통과
4. 자막 타이밍과 TTS 오디오 싱크 오차 ±200ms 이내
5. 생성 실패 씬은 재시도 후에도 실패 시 파이프라인 전체를 멈추지 않고 리포트에 기록

## 비목표 (MVP에서 제외)

- 유튜브 업로드 자동화
- 썸네일 생성
- 다국어 버전
- BGM 자동 작곡 (라이브러리 선곡으로 대체)
