# 00. 개요

## 목표

주제(한 줄) 입력 → 완성된 쇼츠 mp4 출력까지 전 과정을 자동화한다.

## 소재 도메인

**제한이 없다** (ADR-0033 §1). 판별 기준은 하나다 — **그림이 이해를 보조할 수 있는가**
(ADR-0047이 "설명의 일부를 질 수 있는가"에서 낮췄다).

과제는 흥미를 유발하고 질 좋은 정보를 1분에 효과적으로 전달하는 것이고(ADR-0047 첫 원칙)
그림은 그 전달을 보조하는 수단이므로, 기준은 도메인이 아니라 **매체 적합성**이다 —
분위기용 삽화만 나오는 소재는 여전히 탈락이다. 국가·시대 제한은 원래 없다 (ADR-0016).
자세한 판별은 스펙 06.

**토픽 하나가 쇼츠 3편이다** (ADR-0056) — 한국어 정본 대본을 일본어·영어로 줄 1:1 번안하고,
영상 클립 풀 하나를 셋이 공유한다. 화면 텍스트가 영어(ASCII)뿐이라 클립은 언어 중립이다.
언어별 분량 엔벨로프는 실측이 쌓이는 대로 `script-rules.json`의 로케일 블록에 넣는다 — 그 전까지
ja·en은 상한만 검사한다. 길이 목표는 **60초 안팎**이다 (ADR-0057 — 90초대는 레퍼런스 채널의
값이었고 사람이 정한 적이 없다).

## 산출물 정의

- 포맷: 9:16 세로, 1080×1920, 30fps, h264 + aac — **언어당 1파일** (`timeline.{ko,ja,en}.mp4`)
- 길이: `specs/schema/script-rules.json`의 `limits.total_seconds` (레퍼런스 실측 엔벨로프 — ko 기준)
- 구성: AI 생성 영상 클립(씬당 1개, 텍스트→영상 — 어댑터는 사람이 고른 영상 라인: 로컬 GPU(기본, 변동비 0) / 유료 API / 그림 우선(MJ, 부활 예약), ADR-0059) + 화면 계측 표시(빨간 치수선·화살표 + 영어 라벨, `info` 씬만) + 전환(디졸브 위주, 하드컷은 서사가 끊기는 자리) + 번인 자막(언어별) + TTS 내레이션(언어별 목소리) + SFX/BGM + 엔딩 실사 컷(있을 때)

## 성공 기준 (MVP)

1. 주제 1개 입력 시 사람 개입(게이트 1회) 외 없이 mp4 3개(ko·ja·en) 생성 완료 — ja·en 대본이 없는 토픽은 ko 1개
2. 대본이 `01-script-template.md`의 **결과 제약**(분량·수미상관) 검증을 통과.
   구조는 소재마다 다르므로 검증하지 않는다 (ADR-0033)
3. 모든 씬이 `specs/schema/scene.schema.json` 검증을 통과
4. 자막 타이밍과 TTS 오디오 싱크 오차 ±200ms 이내
5. 생성 실패 씬은 재시도 후에도 실패 시 파이프라인 전체를 멈추지 않고 리포트에 기록

## 비목표 (MVP에서 제외)

- 유튜브 업로드 자동화
- 썸네일 생성
- BGM 자동 작곡 (라이브러리 선곡으로 대체)
