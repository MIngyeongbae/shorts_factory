# 00. 개요

## 목표

주제(한 줄) 입력 → 완성된 쇼츠 mp4 출력까지 전 과정을 자동화한다.

## 소재 도메인

**한국 문화기술사 + 건축·토목** (ADR-0015). "이 물건을 왜 이렇게 만들었는가"에 답이 있는
소재만 다룬다.

- 포함: 공예·생산 기술(도자·한지·옻칠·금속활자), 저장·보존 기술(장·김치·석빙고·사고),
  인쇄·기록, 측정·역법, 성곽·궁궐·치수·도시계획
- 제외: 예술 양식·미의식·사상, 세시풍속·놀이·음악 — 실패한 대안의 사료도 구체적 숫자도
  없어 7단 구조를 채우지 못한다

경계 소재(석빙고, 가마, 사고)가 오히려 품질이 좋아 두 갈래를 합쳐 둔다. 다른 도메인
(과학사 일반, 해외 유적, 다국어판)은 이 리포지터리를 넓혀서 담지 않는다. 기능이 확정된 뒤
분기하거나 도메인 팩을 얹는다 — 무엇이 도메인 의존인지는 첫 편을 만들어봐야 안다.

## 산출물 정의

- 포맷: 9:16 세로, 1080×1920, 30fps, h264 + aac
- 길이: 90~102초 (쇼츠 한도 내 최대 밀도, 스펙 01 실측 엔벨로프)
- 구성: AI 생성 배경 영상 + 느린 카메라 모션 + 디졸브 전환 + 번인 자막 + 대형 강조 텍스트 + TTS 내레이션 + SFX/BGM

## 성공 기준 (MVP)

1. 주제 1개 입력 시 사람 개입 없이 mp4 1개 생성 완료
2. 대본이 `01-script-template.md`의 7단 구조 검증을 통과
3. 모든 씬이 `02-beat-schema.md` 스키마 검증을 통과
4. 자막 타이밍과 TTS 오디오 싱크 오차 ±200ms 이내
5. 생성 실패 씬은 재시도 후에도 실패 시 파이프라인 전체를 멈추지 않고 리포트에 기록

## 비목표 (MVP에서 제외)

- 유튜브 업로드 자동화
- 썸네일 생성
- 다국어 버전
- BGM 자동 작곡 (라이브러리 선곡으로 대체)
