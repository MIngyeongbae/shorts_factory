# スパイを暴くための13桁が、なぜ偽造犯の道具になったのか

- 시드: https://namu.wiki/w/주민등록번호
- 매체 적합성: 適合 — 13の枠が分解されて各桁の意味がラベルとして付き、検算の計算と地域コードの地図が画面上でそのまま動く
- 핵심 질문: 偽造を防ぐために入れた仕掛けが、なぜ偽造を容易にしたのか
- 핵심 반전: 最後の1桁は番号が本物かどうかを自分で検算する枠なのに、その式が公開されたことで検問所が通行証の発行所になった
- 보이는 것: 12桁から13桁へ伸びる番号、掛けて足して最後の枠が埋まる計算、地域の4桁が地図上の役所に落ちる場面、2020年以降に後半がランダムに散らばる流れ
- 차별점: 視聴者の財布に今も入っている番号が、それ自体で設計図であり流出経路でもあるということ

## 대본

スパイを暴くための番号が、なぜ偽造しやすくなったのでしょうか。
1968年、北朝鮮の工作員が朴正煕大統領を狙います。
政府は同年11月、全国民に12桁の番号を配ります。
最初の番号は大統領本人、110101-100001。
でもこの番号に生年月日はありません。地域と順番だけ。
本物かどうかは、住民登録票を調べるしかありません。
そこで1975年、13桁に増やし、検算用の桁を足します。
前の12桁を決まった式に入れると、最後の数字が出ます。
番号ごとに検問所を持ち歩くようなものでした。
計算が合わなければ偽物。偽造は終わったはずでした。
問題は、その式がネットでそのまま広まったことです。
規則さえ知れば通る偽番号が、数秒で量産されました。
後半の4桁には、出生届を出した役所が刻まれていました。
番号を見て湖南出身は採らない、という求人まで出ました。
結局2020年、新しく受ける番号は性別以外ランダムになります。
スパイを探すための番号が、今は私を隠す側になりました。
