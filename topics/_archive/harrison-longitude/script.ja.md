# 時計1つで海を解いた大工、賞金は最後まで受け取れなかった

- 시드: https://en.wikipedia.org/wiki/John_Harrison
- 매체 적합성: 適合 — 地球儀の経線、港の時刻と船上の時刻がずれていく2つの時計、地図の上で縮まる推定位置と実際の位置、H4の実物と2つの金属を貼り合わせた棒まで、絵がすべて理解を担う
- 핵심 질문: 大海の真ん中で自分が東西のどこにいるかをどう知るのか、そしてそれを解いた人はなぜ賞金を受け取れなかったのか
- 핵심 반전: 位置の問題が実は時間の問題だったこと、そして審査席に座った人物が競合する方法の当事者だったこと
- 보이는 것: 2つの時計の時差 → 地図上の経度差に変換される過程、試験航海の誤差が点で打たれる比較
- 차별점: 学者ではなく田舎の大工が木の時計から始めて懐中時計で終え、正式な賞金は誰にも渡らなかった

## 대본

2万ポンドの賞金を、解いた本人が受け取れませんでした。
18世紀の船は、南北はわかっても東西が測れません。
1707年、シリー諸島で軍艦4隻が沈みます。
1,400人が死に、議会は1714年、2万ポンドを懸けました。
答えを出したのは学者ではなく、田舎の大工ジョン・ハリソンです。
方法はこうです。出港の瞬間の時刻を、瓶に詰めて運ぶんです。
現地の正午に時計が2時なら、2時間分だけ西にいます。
揺れる船、塩、温度差。ニュートンさえ作れないと見ていました。
ハリソンは40年かけ、2つの金属を貼り合わせて温度を抑えます。
1761年、懐中時計ほどのH4がジャマイカへ渡ります。
81日後の誤差は5秒。地図では1海里、港のすぐ手前でした。
ところが委員会は、運が良かっただけだと賞金を先送りします。
再試験も通りました。月の観測法より3倍正確です。
ところが、その月の観測法を推していたマスケリンが審査席に座ります。
彼の報告は否定的。H4は2度勝っても、落とされます。
結局80歳になって国王が動き、8,750ポンドが出ます。
2万ポンドは、ついに誰の手にも渡りませんでした。

## 주장

- [줄 1] 経度賞金の最高額は2万ポンドで、ハリソンはこの正式な賞金を受け取れなかった — 확인 — 출처: Wikipedia "John Harrison" 도입부
- [줄 2] 南北の位置(緯度)は天体観測で求められたが、東西の位置(経度)は基準を取りにくく、推測航法の累積誤差が難破と人命損失につながった — 확인 — 출처: 같은 문서 "Longitude problem"
- [줄 3] 1707年のシリー諸島海軍惨事があり、戦列艦15隻を含む21隻の艦隊のうち軍艦4隻(Association·Eagle·Romney·Firebrand)が難破した — 정정 완료("艦隊が丸ごと座礁" → "軍艦4隻が沈没") — 출처: Wikipedia "Scilly naval disaster of 1707"
- [줄 4] この惨事の死者は1,400~2,000人と推定され、この衝撃の上で1714年の経度法が最大2万ポンド(経度誤差0.5度以内)の報奨を掲げた — 확인 — 출처: Wikipedia "Scilly naval disaster of 1707" / "Longitude Act 1714"
- [줄 5] ジョン・ハリソンはヨークシャー・ファウルビー出身の大工(joiner)であり時計職人で、父の大工仕事に従いながら余暇に時計を作った — 확인 — 출처: 같은 문서 도입부 / "Early life"
- [줄 6] ハリソンの手法は、基準地(例:グリニッジ)の時刻を正確に保つ時計を船に積むことだった — 확인 — 출처: 같은 문서 "Longitude problem"
- [줄 7] 基準地の時刻と現地時刻の差が経度差に換算される(ゲンマ・フリシウスが提唱した原理)。基準時が進んでいれば西であり、1時間の時差は経度15度である — 확인 — 출처: 같은 문서 "Longitude problem"
- [줄 8] 温度・気圧・湿度の変化、塩分による腐食、船の動きが難題であり、ニュートンとホイヘンスはそのような時計が作れるかを疑い、月距法を好んだ — 확인 — 출처: 같은 문서 "Longitude problem"
- [줄 9] ハリソンは1730年の設計提示から1773年の報奨まで数十年を費やし、バイメタル・ストリップ(2つの金属を貼り合わせ熱膨張を打ち消す装置)を残した。H4の温度補正もバイメタル・ストリップ方式である — 확인 — 출처: 같은 문서 도입부 / "H4"
- [줄 10] H4は直径約13cm(5.2インチ)の銀製ペアケースに収められた、大型の懐中時計に似た時計で、1761年11月18日に50門艦HMS Deptfordでポーツマスを発ち、ジャマイカのキングストンへ向かった — 확인 — 출처: 같은 문서 "H4"
- [줄 11] 81日5時間の航海の後、H4は(初期誤差3秒と日差の補正後)5秒遅れており、これは経度1.25分、約1海里の誤差に当たる — 확인 — 출처: 같은 문서 "H4"
- [줄 12] 経度委員会は精度が運かもしれないとして追加試験を求め、6年かかった製作が実用性の要件を満たすかも問題にした — 확인 — 출처: 같은 문서 "H4"
- [줄 13] バルバドスの再試験でH4は39秒以内、ブリッジタウンの経度誤差は10マイル未満であり、マスケリンの月距法は30マイルだった(3倍以上の差)。これは2万ポンドの基準線(0.5度≒30海里)を大きく上回る — 확인 — 출처: 같은 문서 "H4" / "Longitude Act 1714"
- [줄 14] ネヴィル・マスケリンはバルバドスで月距法を試験して戻った後、王室天文官に任命され、経度委員会に加わることになった — 확인 — 출처: 같은 문서 "H4"
- [줄 15] マスケリンはH4に否定的な報告を出し(日差は誤差の相殺にすぎないとして補正を認めなかった)、H4は先の2回の試験に通っていたにもかかわらず委員会の要件で落とされた — 정정 완료(인과 주장 "심판이 됐으니 부정적이었다"는 시드에 근거 없고 사학계가 반박하므로 삭제, 확인된 사실로 교체) — 출처: 같은 문서 "H4" / Royal Society "Hero or villain? Nevil Maskelyne's posthumous reputation"
- [줄 16] ジョージ3世が1772年5~7月にH5を10週間みずから試験して1日1/3秒以内の精度を確認し議会に圧力をかけ、1773年に80歳のハリソンは議会から8,750ポンドを受け取った — 확인 — 출처: 같은 문서 "H4"
- [줄 17] 正式な経度賞金はハリソンを含め誰にも授与されたことがない(ただしハリソンの生涯受領総額は£23,065) — 확인 — 출처: 같은 문서 "H4"

## 읽기

2万ポンドのしょうきんを、といたほんにんがうけとれませんでした。
18世紀のふねは、なんぼくはわかってもとうざいがはかれません。
1707年、シリーしょとうでぐんかん4隻がしずみます。
1,400人がしに、ぎかいは1714年、2万ポンドをかけました。
こたえをだしたのはがくしゃではなく、いなかのだいくジョン・ハリソンです。
ほうほうはこうです。しゅっこうのしゅんかんのじこくを、びんにつめてはこぶんです。
げんちのしょうごにとけいが2時なら、2時間ぶんだけにしにいます。
ゆれるふね、しお、おんどさ。ニュートンさえつくれないとみていました。
ハリソンは40年かけ、2つのきんぞくをはりあわせておんどをおさえます。
1761年、かいちゅうどけいほどのH4がジャマイカへわたります。
81日後のごさは5秒。ちずでは1海里、みなとのすぐてまえでした。
ところがいいんかいは、うんがよかっただけだとしょうきんをさきおくりします。
さいしけんもとおりました。つきのかんそくほうより3倍せいかくです。
ところが、そのつきのかんそくほうをおしていたマスケリンがしんさせきにすわります。
かれのほうこくはひていてき。H4は2度かっても、おとされます。
けっきょく80歳になってこくおうがうごき、8,750ポンドがでます。
2万ポンドは、ついにだれのてにもわたりませんでした。
