# マラソン最後の195メートルは誰が加えたのか

- 시드: https://en.wikipedia.org/wiki/Marathon
- 매체 적합성: 適合 — オリンピックごとの距離の変化と、1908年のコースが王室観覧席まで延びる過程を地図とトラックで見せられる
- 핵심 질문: マラソンはなぜ42キロメートルではなく42.195キロメートルなのか？
- 핵심 반전: 古代の伝令が走った距離ではなく、1908年ロンドンオリンピックのコースが現代の基準になった
- 보이는 것: 約40キロメートルだった初期のコースが、ウィンザー城と競技場のトラックを経て42.195キロメートルになる流れ
- 차별점: 26マイルの道路と王室観覧席前までの385ヤードを分け、最後の195メートルの正体を説明する

## 대본

マラソンは、なぜきりのいい42キロメートルではないのでしょう？
残りの195メートルには、古代より意外な事情があります。
最初からこの数字だったと思いがちですよね。
でも初期オリンピックの距離は、会場ごとに違いました。
1896年アテネ大会は、約40キロメートルでした。
マラトンからアテネへ続く道を手本にした距離です。
ところが1908年ロンドンで、コース設計が複雑になります。
スタートはウィンザー城、ゴールはホワイトシティ・スタジアムでした。
主催者はまず、約26マイルの道を設定しました。
そして王室観覧席の前にゴールを置いたのです。
入口が変わると、トラック区間は1周から385ヤードに縮みました。
街路の先に王室の席を定規のように当てたわけです。
その結果、その日の公式距離は42.195キロメートル。
それでも、すぐ世界共通の規格にはなりませんでした。
その後のオリンピックでも、距離はまた短くなったり長くなったりします。
1921年、国際陸上競技連盟がロンドンの距離を標準に選びました。
だから最後の195メートルには、王室観覧席の名残があるのです。

## 주장

- [줄 1~2] 現代のマラソンの標準距離は42.195キロメートル（26マイル385ヤード）である — 확인 — 출처: Distance
- [줄 2] この距離の由来は古代の伝令の走行距離ではなく、1908年ロンドンオリンピックのコースである — 확인 — 출처: Origin, Distance
- [줄 3~4] 初期オリンピックのマラソン距離は固定されず、開催地ごとのコースによって異なった（1900年40.26km、1904年40km、1906年41.86km） — 확인 — 출처: Distance
- [줄 5~6] 1896年オリンピックのマラソンは、マラトンからアテネへ続く、より長く平坦な道を手本にした約40キロメートルのコースだった — 확인 — 출처: Origin, Distance
- [줄 7~10] 1908年ロンドンオリンピックのコースは、ウィンザー城を出発し、ホワイトシティ・スタジアムの王室観覧席前で終わるよう設計された（IOCは1907年に「約25マイルまたは40km」と定めたが、主催者は26マイルのコースを設定した） — 확인 — 출처: 1908 Olympics, Distance
- [줄 9] 競技場へ入る前までに計画された道路区間は「約26マイル」だった — 확인 — 출처: 1908 Olympics
- [줄 11] 当初の計画はトラック1周（586ヤード2フィート、約536m）だったが、王室専用入口がトラックへ直接つながっていなかったため、入口と走行方向を変え、トラック区間は385ヤード（352m）に短縮された — 정정 반영 — 출처: 1908 Olympics
- [줄 12] ゴール地点は王室観覧席前に固定され、トラック区間はその地点を基準に測られた — 확인 — 출처: 1908 Olympics
- [줄 13] 26マイルと385ヤードを合わせた1908年の公式距離は42.195キロメートルだった（公式表記は「約26マイル＋トラック385ヤード」） — 정정 반영 — 출처: 1908 Olympics
- [줄 14~15] 1908年以降も、1912年（40.2km）と1920年（42.75km）のオリンピックマラソンは異なる距離で行われた — 확인 — 출처: Distance의 Olympic marathon distances 표
- [줄 16] 国際陸上競技連盟（IAAF、当時の国際アマチュア陸上競技連盟）は、1921年5月に1908年ロンドンオリンピックの距離をマラソンの標準に定めた — 확인 — 출처: Distance, 1908 Olympics
- [줄 17] 現代の標準距離の最後の195メートルは、王室観覧席前をゴールとした1908年のコースに由来する（王室観覧席と直接関係する区間自体は385ヤード＝352m） — 확인 — 출처: 1908 Olympics

## 읽기

マラソンは、なぜきりのいい42キロメートルではないのでしょう？
のこりの195メートルには、こだいよりいがいなじじょうがあります。
さいしょからこのすうじだったとおもいがちですよね。
でもしょきオリンピックのきょりは、かいじょうごとにちがいました。
1896年アテネたいかいは、やく40キロメートルでした。
マラトンからアテネへつづくみちをてほんにしたきょりです。
ところが1908年ロンドンで、コースせっけいがふくざつになります。
スタートはウィンザーじょう、ゴールはホワイトシティ・スタジアムでした。
しゅさいしゃはまず、やく26マイルのみちをせっていしました。
そしておうしつかんらんせきのまえにゴールをおいたのです。
いりぐちがかわると、トラックくかんは1周から385ヤードにちぢみました。
がいろのさきにおうしつのせきをじょうぎのようにあてたわけです。
そのけっか、そのひのこうしききょりは42.195キロメートル。
それでも、すぐせかいきょうつうのきかくにはなりませんでした。
そのごのオリンピックでも、きょりはまたみじかくなったりながくなったりします。
1921年、こくさいりくじょうきょうぎれんめいがロンドンのきょりをひょうじゅんにえらびました。
だからさいごの195メートルには、おうしつかんらんせきのなごりがあるのです。
