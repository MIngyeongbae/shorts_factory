# 板を全部取り替えた船 — それはまだ同じ船なのか

- 시드: https://namu.wiki/w/테세우스의%20배
- 매체 적합성: 適合 — 板が1枚ずつ交換される船、外した板で組み立てられる2隻目の船、破壊された城壁と儀軌の図面、復元された水原華城まで、画面が論旨の各段階をそのまま見せる
- 핵심 질문: 元の木が一片も残っていない船を、それでも同じ船と呼べるのか
- 핵심 반전: この問題は実際に判定されている — ユネスコは残った元の材料の量ではなく「記録」を基準にする。水原華城は華城城役儀軌のおかげで世界遺産になり、バグラティ大聖堂は根拠のない復元で資格を失った
- 보이는 것: 板の交換 → 船が2隻に分かれる → 破壊された華城と儀軌の図面 → 復元された城壁 / 剥奪のスタンプ
- 차별점: 2000年前の思考実験に対して、国際規定がすでに下している判定文が存在するという点
- 여운: あなたは今、何によって記録されていますか

## 대본

哲学の授業に出てきそうな問いに、国際機関が答えを出しました。
アテネはテセウスが乗って帰った船を数百年保存しました。
腐った板を新しい板に取り替え続けながら。
ついに最後の1枚まで替わります。元の木は何も残りません。
哲学者ホッブズが、ここにひとひねり加えました。
外した古い板を集めて、同じ船をもう1隻造ったのです。
船は2隻。どちらが本物のテセウスの船でしょう？
他人事ではありません。私たちの体も80日で全細胞の数だけ入れ替わります。
ところが、これを実際に判定する人たちがいます。
崩れ落ちた文化財を建て直す人たちです。
ユネスコが見るのは、残った板の枚数ではありません。
元の材料と確かな記録が残っているかどうかです。
水原華城は大きく壊れましたが、工事記録『華城城役儀軌』が残っていました。
その記録どおりに甦ったおかげで世界遺産になりました。
逆にジョージアのバグラティ大聖堂は、根拠なく直して資格を失いました。
板を全部替えても船は船。記録が途切れた時、船は消えます。

## 주장

- [줄 1] ユネスコは元の材料がほとんど失われた対象も世界遺産として認める(水原華城) — 通念と逆の判定 — 확인 — 출처: 世界遺産条約履行のための作業指針 ¶86 https://whc.unesco.org/en/guidelines/
- [줄 2] テセウスが乗って帰った30本櫂のガレー船を、アテネ人がファレロンのデメトリオスの時代(紀元前317~307年頃)まで保存した — 확인 — 출처: プルタルコス『英雄伝』テセウス 23.1 https://en.wikipedia.org/wiki/Ship_of_Theseus · https://en.wikipedia.org/wiki/Demetrius_of_Phalerum
- [줄 3] アテネ人が腐った板を外し、新しく丈夫な木材に取り替えた — 확인 — 출처: プルタルコスの同じ箇所
- [줄 4] 板がすべて交換され元の木材が残っていない状態がこの逆説の前提(プルタルコス原文ではなく後世の設定) — 확인 — 출처: ホッブズ『De Corpore』(1655) 第2部11章、ローマ法大全 D.5.1.76(アルフェヌス)
- [줄 5·6] トマス・ホッブズが、外した古い板で船2を造る変形を提起した — 확인(伝聞ではなくホッブズ自身の著作に直接記述されているため緩和表現を外した) — 출처: 『De Corpore』ラテン語1655 / 英訳1656、第2部11章 https://rintintin.colorado.edu/~vancecd/phil1020/Hobbes.pdf
- [줄 7] 2隻のうちどちらがテセウスの船なのか、答えは確定していない — 확인 — 출처: https://www.britannica.com/topic/ship-of-Theseus-philosophy
- [줄 8] 人体は1日に約3,300億個(80±20 g)の細胞を入れ替え、約80日で体全体の細胞数に匹敵する数の新しい細胞が作られる。ただし「すべての細胞が入れ替わる」という意味ではない(入れ替わりの86%が血液細胞、脳・心臓の細胞は生涯維持される) — 정정(原案の「ほぼ入れ替わる」を「全細胞の数だけ入れ替わる」に修正) — 출처: Sender & Milo, Nat Med 27:45–48 (2021) https://pubmed.ncbi.nlm.nih.gov/33432173/ · https://wis-wander.weizmann.ac.il/life-sciences/cell-replacement-numbers
- [줄 10] 台本が挙げる2つの復元事例は、火災ではなく戦乱・砲撃で破壊された — 정정(「焼け落ちた」→「崩れ落ちた」) — 출처: https://en.wikipedia.org/wiki/Hwaseong_Fortress · https://en.wikipedia.org/wiki/Bagrati_Cathedral
- [줄 11·12] ユネスコは再建を「完全で詳細な記録」に基づく場合にのみ認め、推測に基づく復元を禁じている — 확인 — 출처: ユネスコ作業指針 ¶86 https://whc.unesco.org/en/guidelines/ (引用句「元の材料と確かな記録への尊重」「推測が始まる地点で止まる」はユネスコではなく **ICOMOS** ヴェニス憲章1964 第9条 https://civvih.icomos.org/wp-content/uploads/2022/03/Charter-of-Venice_1964.pdf)
- [줄 13·14] 水原華城(1794~96年築造)は日本統治期と朝鮮戦争で大きく破壊されたが、1801年刊行の『華城城役儀軌』に従って1975~79年に復元され、1997年に世界遺産へ登録された — 확인 — 출처: https://whc.unesco.org/en/list/817/ · https://en.wikipedia.org/wiki/Hwaseong_Fortress
- [줄 15] ジョージアのバグラティ大聖堂は1994年登録、2010年に危機遺産リスト入りを経て、2017年の第41回世界遺産委員会で遺産の範囲から除外された。理由は「真正性と完全性を損なう大規模な再建」であり、2010年の合同調査団は原形についての十分な資料がないまま再建する計画を問題視した — 확인 — 출처: https://en.wikipedia.org/wiki/Former_UNESCO_World_Heritage_Sites · https://whc.unesco.org/en/soc/920
- [줄 16] アイデンティティの根拠は残った材料の量ではなく記録であり、記録が途切れれば維持の根拠そのものが消える — 확인 — 출처: 作業指針 ¶86 + 華城・バグラティ両判定の対照

## 읽기

てつがくのじゅぎょうにでてきそうなといに、こくさいきかんがこたえをだしました。
アテネはテセウスがのってかえったふねをすうひゃくねんほぞんしました。
くさったいたをあたらしいいたにとりかえつづけながら。
ついにさいごの1枚までかわります。もとのきはなにものこりません。
てつがくしゃホッブズが、ここにひとひねりくわえました。
はずしたふるいいたをあつめて、おなじふねをもう1隻つくったのです。
ふねは2隻。どちらがほんもののテセウスのふねでしょう？
ひとごとではありません。わたしたちのからだも80日でぜんさいぼうのかずだけいれかわります。
ところが、これをじっさいにはんていするひとたちがいます。
くずれおちたぶんかざいをたてなおすひとたちです。
ユネスコがみるのは、のこったいたのまいすうではありません。
もとのざいりょうとたしかなきろくがのこっているかどうかです。
すいげんかじょうはおおきくこわれましたが、こうじきろく『かじょうじょうえきぎき』がのこっていました。
そのきろくどおりによみがえったおかげでせかいいさんになりました。
ぎゃくにジョージアのバグラティだいせいどうは、こんきょなくなおしてしかくをうしないました。
いたをぜんぶかえてもふねはふね。きろくがとぎれたとき、ふねはきえます。
