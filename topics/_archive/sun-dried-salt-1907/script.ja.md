# 天日塩 — 私たちが「伝統」と呼ぶあの塩は、1907年の輸入品です

- 시드: https://namu.wiki/w/천일염
- 매체 적합성: 適合 — 塩田の床の変遷(土→タイル→ビニールシート)、降水集中度の数値比較、インチョンのチュアンからシナンへ南下する地図が、そのまま因果を見せてくれる
- 핵심 질문: キムチに入れるあの粗い塩が伝統でないなら、なぜ国民全員が使うようになったのか?
- 핵심 반전: 先祖は天日製塩を知らなかったから使わなかったのではなく、塩を作る季節に雨が降り注ぐ朝鮮半島の気候に合わなかったから使わなかったとみられる。それでも導入した理由は、煮るための薪が尽きたことだった
- 보이는 것: 煮塩の窯に積まれた薪の山 → 丸裸の山 → 1907年のチュアン塩田 → 分断で切り離された北の塩田(5,925町歩のうち4,261町歩) → 柔らかいシナンの干潟に敷かれるタイルとビニールシート
- 차별점: 先祖がこの塩を「倭塩(わえん)」と見下して呼んだという記録 — 伝統の正反対から出発した塩

## 대본

キムチに使うあの粗い塩、実は伝統ではなく輸入品です。
朝鮮半島の伝統的な塩は、海水を煮詰めた煮塩でした。
天日塩が始まったのは1907年、インチョンのチュアン塩田です。
日本が日清戦争で手にした台湾の方式を持ち込みました。
では、ご先祖はこの簡単なやり方を知らなかったのでしょうか？
いいえ、知っていて使わなかったようです。天が味方しなかったのです。
天日塩には、雨の来ない長い乾季が要ります。
韓国は塩を作る夏に、年間降水量の54%が集中します。
梅雨の庭で洗濯物を干すようなものでした。
それでも踏み切った理由は、煮るための薪がなかったからです。
煮塩は薪を食います。でも山はすでに丸裸でした。
当のご先祖は日本の塩だと、倭塩と呼んで見下したのです。
流れを変えたのは戦争。塩田の10のうち7が北にありました。
残ったのは柔らかいシナンの干潟。そこに無理やり塩田を敷きました。
土が浮くのでタイルを敷き、乾かないのでビニールまで敷きました。
こうして70年、輸入技術が伝統の座に収まりました。
あの粗い塩は伝統ではなく、事情が生んだ結果というわけです。

## 주장

- [줄 1] 天日塩はキムチや醤類に使う粗塩であり、韓国の伝統的な製法ではなく大韓帝国末期に流入した方式である — **確認** ([全羅南道庁](https://solarsalt.jeonnam.go.kr/main/cm/cntnts/cntntsView.do?mi=9102&cntntsId=65), [CJニュースルーム](https://cjnews.cj.net/천일염-꽃소금-맛소금-다른-점이-뭐야/))
- [줄 2] 朝鮮半島の伝統的な塩は、海水を釜に入れて煮詰めて作る煮塩である — **確認** ([ウリ歴史ネット](https://contents.history.go.kr/mobile/km/view.do?levelId=km_012_0070_0030_0020), [農民新聞](https://www.nongmin.com/article/20120819033415))
- [줄 3] 天日塩の始まりは1907年にインチョンのチュアンへ築かれた**台湾式天日製塩の試験塩田(1町歩)**である — **確認** ([弥鄒忽文化大典](http://www.grandculture.net/michuhol/toc/GC04700852), [全羅南道庁](https://solarsalt.jeonnam.go.kr/main/cm/cntnts/cntntsView.do?mi=9102&cntntsId=65)) / *訂正: 「最初のタイル式塩田」は誤り — タイル床は後代の段階*
- [줄 4] 1906年に台湾総督府専売局の技手が干潟を調査し、1907年に度支部(統監府体制)がチュアンへ台湾式の天日製塩場を建てた。台湾は日清戦争の結果、下関条約で日本に割譲された土地である — **確認** ([弥鄒忽文化大典](http://www.grandculture.net/michuhol/toc/GC04700852), [下関条約](https://ko.wikipedia.org/wiki/시모노세키_조약))
- [줄 5~6] 先祖は天日製塩の方式を知らなかったのではなく、気候が合わないために煮て作っていた — **有力説** (原典のナムウィキ以外に文献未確認) / *訂正: 줄 6を「知っていて使わなかったようです」と推定表現に*
- [줄 7] 天日塩には雨の降らない乾期が長く続く必要がある — **確認**(蒸発濃縮の原理および世界の産地に共通する条件) / *訂正: 「年平均25℃以上・地中海性気候(フランス・スペイン)」は**根拠なし** — ゲランドはCfb海洋性気候([出典](https://www.whereandwhen.net/when/europe/pays-de-la-loire/guerande/))、世界の上位生産国は中国・アメリカ・インド・オーストラリア・メキシコ([USGS](https://pubs.usgs.gov/periodicals/mcs2024/mcs2024-salt.pdf)) → 削除*
- [줄 8] 韓国は年降水量1,306.3mmのうち夏に710.9mm(**54%**)が集中し、塩の生産期と雨期が重なる — **確認** ([気象庁](https://www.weather.go.kr/w/climate/statistics/korea.do)) / *訂正: 「年平均気温15℃」は誤り — 全国平年値は**12.8℃**(地域別7~15℃)([気象庁平年値](https://data.kma.go.kr/normals/index.do)) → 気温の数値を削除。「蒸発量1,200~1,400mm」「海水濃度2%以下」は**根拠なし** → 不使用*
- [줄 10] 朝鮮政府・朝鮮総督府が天日塩を奨励した背景は、薪(火木)の調達難だった — **確認** ([ニュースビジョンe](http://www.nvp.co.kr/news/articleView.html?idxno=309786), [国家記録院](https://theme.archives.go.kr/next/forest/background/immediateCausesOfDeforestation.do))
- [줄 11] 煮塩は薪の消費が大きく、当時の山林はすでに荒廃していた(1910年の健全な山林21%) — **有力説→訂正** ([国家記録院](https://theme.archives.go.kr/next/forest/background/processAndCausesOfDeforestation.do)) / *訂正: 丸裸の山の最大の直接原因はオンドル用の薪の採取であるため、「煮塩が山を丸裸にした」という因果を「山はすでに丸裸だった」に修正*
- [줄 12] 天日塩は「日本人が持ち込んだ塩」という意味の倭塩と呼ばれた — **確認** ([ニュースビジョンe](http://www.nvp.co.kr/news/articleView.html?idxno=309786)) / *訂正: 「苦味ゆえに蔑まれた」は**有力説** → 削除し、確認された語源に差し替え*
- [줄 13] 1945年、官営の天日塩田5,925町歩のうち4,261町歩(**71.9%**)が北にあり、南にはチュアン・ソレ・ナムドン・クンジャなど1,664町歩しかなかった。1943年に造成された延白の海南塩田1,250町歩も休戦ラインの北へ渡った — **確認** ([仁川日報](http://www.incheonilbo.com/news/articleView.html?idxno=1040699)) / *訂正: 「硬い干潟は平安道・黄海道・京畿道だけ」は**根拠なし** → 検証済みの分布数値(「10のうち7」)に差し替え*
- [줄 14] そこで広い泥質干潟を持つ全羅南道シナン一帯に塩田を造成し、戦後の塩増産5か年計画(1952~56)で西南海岸の塩田が大量に開発された — **確認** ([シナンの干潟](https://www.getbolworldheritage.org/k_getbol/shinan), [仁川日報](http://www.incheonilbo.com/news/articleView.html?idxno=1040699)) / *参考: シナン最初の塩田は1947年の飛禽面 — 戦争は拡大を爆発させた契機([新安郡庁](https://www.shinan.go.kr/home/www/dept_info/economy/salt_info/salt_info_10/page.wscms))*
- [줄 15] 塩田の床は土板 → 甕貝板(甕の破片) → セラミックタイル → PVCシートへと変遷し、1980年代以降はシート塩が主流(現在およそ90%)である — **確認** ([特許 KR20150006989A](https://patents.google.com/patent/KR20150006989A/ko), [ル・モンド・ディプロマティーク](https://www.ilemonde.com/news/articleView.html?idxno=14882))
- [줄 16] 1955年に35万トンを生産して初めて自給を達成し、そこから約70年が経った — **確認** ([全羅南道庁](https://solarsalt.jeonnam.go.kr/main/cm/cntnts/cntntsView.do?mi=9102&cntntsId=65))
- [줄 17] 天日塩の拡大は伝統の継承ではなく、燃料・分断・気候という条件の結果である — **確認** (上記の根拠の総合)

## 읽기

キムチにつかうあのあらいしお、じつはでんとうではなくゆにゅうひんです。
ちょうせんはんとうのでんとうてきなしおは、かいすいをにつめたにじおでした。
てんぴじおがはじまったのは1907年、インチョンのチュアンえんでんです。
にほんがにっしんせんそうでてにしたたいわんのほうしきをもちこみました。
では、ごせんぞはこのかんたんなやりかたをしらなかったのでしょうか？
いいえ、しっていてつかわなかったようです。てんがみかたしなかったのです。
てんぴじおには、あめのこないながいかんきがいります。
かんこくはしおをつくるなつに、ねんかんこうすいりょうの54%がしゅうちゅうします。
つゆのにわでせんたくものをほすようなものでした。
それでもふみきったりゆうは、にるためのまきがなかったからです。
にじおはまきをくいます。でもやまはすでにまるはだかでした。
とうのごせんぞはにほんのしおだと、わえんとよんでみくだしたのです。
ながれをかえたのはせんそう。えんでんの10のうち7がきたにありました。
のこったのはやわらかいシナンのひがた。そこにむりやりえんでんをしきました。
つちがうくのでタイルをしき、かわかないのでビニールまでしきました。
こうして70年、ゆにゅうぎじゅつがでんとうのざにおさまりました。
あのあらいしおはでんとうではなく、じじょうがうんだけっかというわけです。
