# 1万年後の人に「ここを掘るな」と伝える方法

- 시드: https://en.wikipedia.org/wiki/Long-term_nuclear_waste_warning_messages
- 매체 적합성: 適合 — 石のトゲが並ぶ荒野、家ほどの黒いブロックの迷路、口笛を吹く建物、色が変わる猫まで、すべて実在する設計案なので、絵がそのまま説明になる
- 핵심 질문: 今使っている文字がすべて消えた後でも読める警告文を、どう作るのか
- 핵심 반전: 記念碑は本来、記憶されるために建てる。ところがこれは「ここには何の価値もない」と刻む。答えが文章から恐怖へ、そして歌へと移っていく
- 보이는 것: 石に刻んだ文章 → 土地全体を武器に変えた景観設計 → 生きた猫とサビへ、情報を入れる器が変わり続ける流れ
- 차별점: 核廃棄物の問題なのに呼ばれたのは技術者ではなく言語学者で、成果物は報告書ではなく歌だった

## 대본

1万年後の人に「ここを掘るな」と伝えるには、どうしますか？
アメリカが砂漠の地下に埋めた核廃棄物は、少なくとも1万年は危険です。
でも言葉は着替え続ける服で、その頃には読めません。
そこで1981年、アメリカは言語学者まで呼び集めました。
1993年にサンディア研究所が出した答えは、この文章でした。
「ここは名誉の場所ではない。称えるべき業績はここにはない。」
「ここにある物は危険で、我々には忌まわしかった。これは警告だ。」
でも文字は信じられない。だから土地そのものを恐ろしくします。
21メートルの石のトゲを、斜めに傾けて突き刺す案です。
家ほどの黒い岩を数百個並べた道は、どこにも通じません。
風が吹くと物悲しい口笛が鳴る建物も設計しました。
実はもっと奇妙な提案が、すでに1984年に出ていました。
放射線のそばで体の色が変わる猫を、作ろうというんです。
「猫の色が変わったら逃げろ」。そんな歌まで添えて。
頭から離れないサビなら、1万年もつと考えたわけです。
そして2014年、その歌は本当に世に出ました。
言葉が全部着替えても「ここを掘るな」だけは残るように。

## 주장

- [줄 1·2] 核廃棄物処分場の警告メッセージは、1万年規模の未来に人間が掘り進んでくるのを防ごうとする試みだ — 확인 / 기사 도입부
- [줄 2] アメリカの対象施設は Waste Isolation Pilot Plant(ニューメキシコ州カールズバッド南東のチワワ砂漠、地下約0.5マイルの岩塩層)であり「砂漠の地下」は正確 — 확인 / https://www.energy.gov/em/waste-isolation-pilot-plant-wipp
- [줄 2] 「1万年」は危険が終わる時点ではなく、EPA 40 CFR 191 の規制期間であり標識の設計期間だ(Pu-239 の半減期は約24,100年) — 정정 반영: 「少なくとも1万年は」 / https://www.epa.gov/radiation/environmental-radiation-protection-standards-management-and-disposal-spent-nuclear-fuel
- [줄 3] 現代の文字言語はその時まで生き残らない可能性が高く、だから研究チームは絵文字と敵対的建築を併せて検討した — 확인 / 기사 "Written messages"
- [줄 4] 核記号論は1981年のアメリカ DOE・Bechtel による Human Interference Task Force から始まり、構成員には技術者・物理学者だけでなく言語学者・人類学者・記号論学者が含まれた。言語学者 Thomas Sebeok が1981年に顧問として加わった — 확인 / https://en.wikipedia.org/wiki/Human_Interference_Task_Force
- [줄 5] 1993年のサンディア国立研究所(Sandia National Laboratories)報告書が、未来の訪問者に伝えるメッセージの文例を示した — 확인 / 기사 "Message", 각주 1(Trauth, Hora, Guzowski, 1993)
- [줄 6] "This place is not a place of honor... no highly esteemed deed is commemorated here... nothing valued is here." の訳 — 확인 / 기사 "Message"
- [줄 7] 原文は "What is here was dangerous and repulsive to us" で、"The danger is still present, in your time" が続く — 정정 반영: 「あった物」→「ある物」 / 기사 "Message"
- [줄 8] 報告書は、危険な放出、身体的危害を連想させる形状、破壊または汚染されたかのような「忌避される土地」の概念を伝える物理的標識の設計を検討した — 확인 / 기사 "Physical markers"
- [줄 9] Leaning Stone Spikes: 高さ70フィート(21m)、底面幅15〜20フィート、1:14 の傾き。数値は正確だが「四方に」は寸法のない Landscape of Thorns の特徴で、二つの設計が混ざっていた — 정정 반영: 「斜めに傾けて」 / https://wipp.energy.gov/pdfs/site_markers.pdf
- [줄 10] Forbidding Blocks: 黒く染めた家ほどの岩の塊を数百個(一辺約25フィート)不規則な格子状に配置し、どこにもつながらない「街路」を作る — 확인 / 기사 "Physical markers"
- [줄 11] WIPP 情報センター構想: 40×32×10フィートの花崗岩・コンクリート構造物に風が通るとき「不協和で物悲しい(dissonant and mournful)」口笛の音が鳴るようにする提案(レベルIメッセージ) — 확인 / 기사 "Written messages"
- [줄 12] レイ・キャット案は1984年で、1993年のサンディアの景観案より先行する。従来の「だんだん奇妙になる」は時系列が逆 — 정정 반영: 「すでに1984年に」 / https://en.wikipedia.org/wiki/Ray_cat
- [줄 13] Françoise Bastide と Paolo Fabbri が1984年の *Zeitschrift für Semiotik* で、放射線の放出の近くで色が大きく変わる「レイ・キャット(ray cats)」の飼育を提案した — 확인 / 기사 "Cultural research"
- [줄 14] 猫の意味を童話・神話で集団記憶に植えつけ、詩・音楽・絵で受け継ぐという構想。セリフ内の引用符の中の文句は原文の引用ではなく趣旨を移した例 — 확인 / 같은 절
- [줄 15·16] ポッドキャスト 99% Invisible が依頼し、ミュージシャン Emperor X が2014年に作った曲 "10,000-Year Earworm to Discourage Settlement Near Nuclear Waste Repositories (Don't Change Color, Kitty)" は、1万年にわたり世代を継いで伝わるほど中毒性があるよう設計された — 확인 / https://99percentinvisible.org/episode/ten-thousand-years/

## 읽기

1万年ごのひとに「ここをほるな」とつたえるには、どうしますか？
アメリカがさばくのちかにうめたかくはいきぶつは、すくなくとも1万年はきけんです。
でもことばはきがえつづけるふくで、そのころにはよめません。
そこで1981年、アメリカはげんごがくしゃまでよびあつめました。
1993年にサンディアけんきゅうじょがだしたこたえは、このぶんしょうでした。
「ここはめいよのばしょではない。たたえるべきぎょうせきはここにはない。」
「ここにあるものはきけんで、われわれにはいまわしかった。これはけいこくだ。」
でももじはしんじられない。だからとちそのものをおそろしくします。
21メートルのいしのトゲを、ななめにかたむけてつきさすあんです。
いえほどのくろいいわをすうひゃくこならべたみちは、どこにもつうじません。
かぜがふくとものがなしいくちぶえがなるたてものもせっけいしました。
じつはもっときみょうなていあんが、すでに1984年にでていました。
ほうしゃせんのそばでからだのいろがかわるねこを、つくろうというんです。
「ねこのいろがかわったらにげろ」。そんなうたまでそえて。
あたまからはなれないサビなら、1万年もつとかんがえたわけです。
そして2014年、そのうたはほんとうによにでました。
ことばがぜんぶきがえても「ここをほるな」だけはのこるように。
