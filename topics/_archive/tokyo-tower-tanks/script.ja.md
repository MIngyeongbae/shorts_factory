# 東京タワーは戦後に捨てられた戦車で造られた？

- 시드: https://ja.wikipedia.org/wiki/東京タワー
- 매체 적합성: 適合 — 戦車の解体から製鉄、形鋼の製造、タワー上部の組み立てまで、素材の変化を映像化できる。
- 핵심 질문: 戦争で使われた米軍戦車は、どうやって東京の象徴になったのか？
- 핵심 반전: 戦車の鉄はタワー全体ではなく、旧大展望台（現在のメインデッキ、150m）より上に集中的に使われた。
- 보이는 것: 点在する電波塔、戦車の解体、鉄の再加工、東京タワー上部へと続く流れ
- 차별점: 地上を走った約90両の戦車が、放送電波を送る塔の骨組みに変わった歴史

## 대본
東京タワーは、戦争が残した米軍戦車で造られました。
赤と白の観光名所に、なぜ戦車90両が隠れているのでしょう？
1950年代の東京では、放送局ごとに電波塔が立っていました。
チャンネルを変えるたび、家のアンテナも回していました。
必要なのは、遠くまで届く1本の塔、エッフェル塔より高い塔でした。
しかし戦後の日本は、良質な鋼材が不足していました。
そこで朝鮮戦争後に廃棄された米軍戦車が、スクラップ市場に出ます。
古いM4とM47は、修理するより売るほうが得だったのです。
戦車は解体され、鉄は東京製鉄で形鋼になります。
装甲を溶かし、巨大なアンテナの骨に変えたのです。
その鋼材が使われたのは、4,000トンの塔全体ではありません。
旧大展望台、現在のメインデッキより上でした。
約90両分の戦車の鉄が、東京の空を支えています。
333メートルの塔は1958年、着工から543日で完成しました。
点在していた放送電波は、この塔に集まり始めます。
だから東京タワーを見上げたら、境目を探してみてください。
その上には、地上を走った戦車90両の第二の命が立っています。

## 주장

- [줄 1~2] 東京タワーには朝鮮戦争後にスクラップされた米軍戦車約90両分の鉄が使われた — 確認 (출처: 建設 / ja.wikipedia「朝鮮戦争後スクラップにされたアメリカ軍の戦車約90両分」)
- [줄 3~4] 建設前は放送局ごとの電波塔が点在し、チャンネルごとに受信アンテナの向きを変える必要があった — 確認 (출처: 構想 / ja.wikipedia)
- [줄 5] 統合電波塔はエッフェル塔（312m）より21m高い333メートルで設計された — 確認 (출처: 設計 / ja.wikipedia)
- [줄 6] 当時の日本では良質な鋼材が不足していた — 確認 (출처: 建設 /「良質の鋼材に恵まれず」)
- [줄 7] 朝鮮戦争後にスクラップとなった米軍戦車の鉄が使われた — 確認 (출처: 建設 / ja.wikipedia)
- [줄 8] 戦車の型式はM4・M47だった — 確認 (출처: 建設 /『東京タワー99の謎』)
- [줄 8] 米国には旧式戦車を修理するより、売却して新型を造るほうが有利だった — 確認 (출처: 建設 / ja.wikipedia)
- [줄 9] 解体された戦車の鉄は東京製鉄（千住工場）で建築用形鋼（アングル）に加工された — 確認 (출처: 建設 / ja.wikipedia, 東京製鐵公式沿革)
- [줄 11] 東京タワーには合計約4,000トンの鋼材が使われた — 確認 (출처: 建設 /「合計約4,000トン」)
- [줄 12] 戦車由来の鋼材は旧大展望台（現在のメインデッキ、150m）より上に使われた — **訂正** (シードの「特別展望台より上」という記述はテレビ番組の脚注に依存。読売新聞の取材・当事者証言・書籍3冊は「大展望台より上」。国立国会図書館レファレンス協同データベースも資料間の不一致を併記)
- [줄 13] 使用された戦車の鉄は約90両分だった — 確認 (출처: 建設 /「約90両分」)
- [줄 14] 東京タワーは高さ333メートルで、着工（1957.6.29）から543日後の1958年12月23日に完成した — 確認 (출처: 概要・建設)
- [줄 15] 東京タワーは点在していた放送電波塔を1か所に集約するため建設された — 確認 (출처: 構想・電波塔集約)
- [줄 16~17] 戦車由来の鋼材が東京タワー上部に残っている — 確認 (출처: 建設)
- [미기재·반전 후보] 戦車由来の鉄は約1,000〜1,500トンで、タワー総重量の約3分の1 — 確認 (読売新聞 1999.10.11, 東京製鉄証言)

## 읽기
とうきょうタワーは、せんそうがのこしたべいぐんせんしゃでつくられました。
あかとしろのかんこうめいしょに、なぜせんしゃ90両がかくれているのでしょう？
1950年代のとうきょうでは、ほうそうきょくごとにでんぱとうがたっていました。
チャンネルをかえるたび、いえのアンテナもまわしていました。
ひつようなのは、とおくまでとどく1本のとう、エッフェルとうよりたかいとうでした。
しかしせんごのにほんは、りょうしつなこうざいがふそくしていました。
そこでちょうせんせんそうごにはいきされたべいぐんせんしゃが、スクラップしじょうにでます。
ふるいM4とM47は、しゅうりするよりうるほうがとくだったのです。
せんしゃはかいたいされ、てつはとうきょうせいてつでかたこうになります。
そうこうをとかし、きょだいなアンテナのほねにかえたのです。
そのこうざいがつかわれたのは、4,000トンのとうぜんたいではありません。
きゅうだいてんぼうだい、げんざいのメインデッキよりうえでした。
やく90両ぶんのせんしゃのてつが、とうきょうのそらをささえています。
333メートルのとうは1958年、ちゃっこうから543日でかんせいしました。
てんざいしていたほうそうでんぱは、このとうにあつまりはじめます。
だからとうきょうタワーをみあげたら、さかいめをさがしてみてください。
そのうえには、ちじょうをはしったせんしゃ90両のだいにのいのちがたっています。
