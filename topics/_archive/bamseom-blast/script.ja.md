# 汝矣島を造るために爆破した島が、6倍になって戻ってきた

- 시드: https://namu.wiki/w/밤섬
- 매체 적합성: 適合 — 1966年の航空写真、1968年の爆破の瞬間の写真、輪中堤の工事、そして今日の衛星写真が「消した→戻ってきた」を1枚ずつで証明できる
- 핵심 질문: ダイナマイトで丸ごと吹き飛ばした島が、なぜ元より大きくなったのか?
- 핵심 반전: 爆破は島を消したのではなく、水面より上の土を削り取っただけだった — 水中に残った岩盤が砂を受け止める引っかかりになり、島をもう一度育てた
- 보이는 것: 爆破前後の地図の重ね合わせ → パムソムの岩が汝矣島の堤防に積まれる場面 → 岩盤の上に砂が引っかかって積もる断面 → 4.5万㎡から29万㎡へ育つ面積グラフ → 渡り鳥が舞い降りる今の森
- 차별점: 都市が消した土地が、その都市の真ん中でひとりでに復元し、人の立ち入りが禁じられた国際保護湿地になった場所

## 대본

島をまるごと爆破したら、前より大きくなって戻ってきました。
1968年のソウル、漢江の真ん中にあったパムソムの話です。
当時の汝矣島は、雨が降るたびに水に浸かる砂地でした。
ソウル市はここに堤防を巡らせ、新都市を造ろうとします。
ところが建設部が待ったをかけます。洪水はどうするんだ、と。
水を流す川幅1300メートル。それが条件でした。
その流路にちょうど重なったのが、443人が暮らすパムソムです。
住民は先に川の向こうへ移り、島は爆薬で崩れ落ちます。
砕けた岩は運ばれ、汝矣島を囲む堤防になりました。
でも爆弾が削り取ったのは、島の水面から上だけでした。
川底の硬い岩盤は、そっくり残っていたんです。
漢江は雨が降ると増水し、大量の砂を運びます。
その砂が残った岩盤に引っかかり、毎年少しずつ積もりました。
詰まった排水口に髪の毛が絡みつくのと同じです。
1966年に4万5000平方メートルだった島が、今は6倍です。
人が去ると柳が茂り、渡り鳥が舞い降りました。
2012年、ラムサール条約の湿地として国際保護リストに載ります。
消そうとした島は大きくなり、今は許可がないと入れません。

## 주장

- [줄 1·18] **확인** — パムソムは爆破後の堆積で再生し、爆破前より大きな島になり、今も成長を続けている — 한국민족문화대백과사전 / MBC 뉴스데스크(2023)
- [줄 2] **확인** — パムソムは漢江下流の汝矣島と麻浦の間にある中州で、1968年2月10日午後3時に爆破された — 영등포구 문화관광 / 서울신문 「서울택리지」
- [줄 3] **확인** — 爆破前の汝矣島は砂地で、梅雨時に漢江の水位が上がると島の大部分が水没した — 서울&(한겨레)
- [줄 4] **확인** — ソウル市(金玄玉市長)は輪中堤という堤防を築き、汝矣島を現代的な都市・副都心として開発しようとした — 서울&(한겨레)
- [줄 5] **확인** — 建設部が「パムソムは洪水の流れを大きく妨げる」「100年周期の大洪水に備えられない」として待ったをかけた — 세종대왕신문 / 뉴스스페이스
- [줄 6] **확인** — ソウル市と建設部は、漢江本流の幅を1,300mに保ち大洪水時の流路を確保する案で合意した — 서울신문 「서울택리지」 / 뉴스스페이스
- [줄 7] **확인** — 1,300m確保のためパムソムの爆破は避けられなかった / 爆破直前の居住者は443人(世帯数は62・78と出典が食い違うため人数のみ使用) — 뉴스스페이스 / 영등포구 / 서울신문
- [줄 8] **정정 반영** — 住民の移住(1968.1.20~28)が爆破(2.10)より先だった。移住先は麻浦区倉前洞・臥牛山のふもと、つまり川の向こう岸 — 세종대왕신문 / 서울&
- [줄 9] **확인** — パムソムの岩石は汝矣島の輪中堤の石材に、土砂は埋め立てに使われた — 한국민족문화대백과사전 / 세종대왕신문
- [줄 10·11] **확인** — 爆破は水面より上だけを削り取り、水面下の岩盤・残骸が残ってその上に堆積が始まった — 한국민족문화대백과사전
- [줄 12·13] **확인** — 漢江は河状係数が高く流量の変動が大きい。残った岩盤に土砂が引っかかり、年平均およそ4,400㎡ずつ積もった — Landscape Times / 머니투데이
- [줄 15] **정정 반영** — 1966年45,684㎡(米軍による最初の測量) → 2013年279,531㎡(ソウル市GPS測量、約6倍) → 293,012㎡(6.4倍)。シードの「40万㎡・10倍」は他の資料で確認できず破棄 — Landscape Times / 머니투데이 / MBC 뉴스데스크(2023)
- [줄 16] **확인** — 無人島になった後、ヤナギ類の群落とアシが繁茂し、都心の渡り鳥飛来地になった(1986年に飛来地として認定、1999.8.10 ソウル市第1号生態景観保全地域) — 한국민족문화대백과사전 / 영등포구
- [줄 17] **확인** — 2012年6月26日にラムサール条約湿地として登録(国内18番目、登録面積およそ27万㎡) — 영등포구 / 한국민족문화대백과사전
- [줄 18] **확인** — 1999年の生態景観保全地域指定以降、一般人の立ち入りが制限され、研究者も特別許可を得て船で入る — 영등포구 / 서울시 미래한강본부

## 읽기

しまをまるごとばくはしたら、まえよりおおきくなってもどってきました。
1968年のソウル、はんがんのまんなかにあったパムソムのはなしです。
とうじのよいどは、あめがふるたびにみずにつかるすなじでした。
ソウルしはここにていぼうをめぐらせ、しんとしをつくろうとします。
ところがけんせつぶがまったをかけます。こうずいはどうするんだ、と。
みずをながすかわはば1300メートル。それがじょうけんでした。
そのりゅうろにちょうどかさなったのが、443人がくらすパムソムです。
じゅうみんはさきにかわのむこうへうつり、しまはばくやくでくずれおちます。
くだけたいわははこばれ、よいどをかこむていぼうになりました。
でもばくだんがけずりとったのは、しまのすいめんからうえだけでした。
かわぞこのかたいがんばんは、そっくりのこっていたんです。
はんがんはあめがふるとぞうすいし、たいりょうのすなをはこびます。
そのすながのこったがんばんにひっかかり、まいとしすこしずつつもりました。
つまったはいすいこうにかみのけがからみつくのとおなじです。
1966年に4万5000平方メートルだったしまが、いまは6倍です。
ひとがさるとやなぎがしげり、わたりどりがまいおりました。
2012年、ラムサールじょうやくのしっちとしてこくさいほごリストにのります。
けそうとしたしまはおおきくなり、いまはきょかがないとはいれません。
