# 角弓 — 朝鮮最強の弓、その心臓は輸入品でした

- 시드: https://namu.wiki/w/각궁
- 매체 적합성: 適合 — 角と腱と木が重なって一枚の弓になる断面、角が渡ってきた航路とそれが断たれる瞬間、水牛の頭数が増えては消えるグラフまで、すべてが理解を支える絵になる
- 핵심 질문: 朝鮮を代表する武器なのに、なぜ最後まで朝鮮の中だけで作れなかったのか
- 핵심 반전: 伝統の象徴である角弓の心臓は全量が輸入の水牛角で、明がそれを軍需品として持ち出しを禁じ、朝鮮の弓の生産を握っていた
- 보이는 것: 弓の断面の層構造 → 角が来た海路が塞がる地図 → 宮殿で増えた水牛が島へ消えていく流れ
- 차별점: 「我らの伝統の弓」という言葉の裏に、実は数百年分の輸入交渉と失敗した国産化の記録が敷かれているという反転

## 대본

朝鮮最強の武器を、朝鮮は自力で作れませんでした。
角弓は、木に牛の腱と角を重ねて貼った弓です。
外側の腱は伸び、内側の角は押されて力をためます。
おかげで同じ力で引いても、矢ははるかに遠くへ飛びました。
問題はその角。朝鮮の地に水牛はいなかったのです。
水牛の角は、中国・日本・琉球からすべて買うしかありません。
弓の心臓を、まるごと他国の倉庫に預けていたわけです。
明はこれを軍需品として、角の持ち出しを厳しく禁じます。
角弓を作れるかどうかは、明の手の内にありました。
朝鮮も黙ってはいません。水牛を自分で育てることにします。
世祖の時代、琉球から雌雄1対を迎えて育ててみます。
歩みは遅く、成宗の頃にようやく70頭まで増えました。
ところが民家に渡った水牛が、人を突いて怪我をさせます。
水牛は島へ追いやられ、国産化はそこで終わります。
鹿の角や黄牛の角で、代用の弓も試しました。
どれも短く弱く、水牛の角の穴は埋まりませんでした。
それでも朝鮮は契という組合を作り、日本から角を買い入れます。
伝統と呼ばれるあの弓は、実は数百年分の輸入の産物でした。

## 주장

- [줄 1] 朝鮮を代表する弓・黒角弓の中心材料を、朝鮮の中で調達できなかった — 確認 / 우리역사넷 「조선이 일본에서 수입한 물품」, 동국대 HK+ 칼럼
- [줄 2] 角弓は木・牛の腱・角を主材料とする合成弓で、習射用の角弓は水牛角・山桑・竹・樫・樺皮・牛の腱・ニベの浮袋の膠という7つの材で作る — 確認 / 국가유산진흥원 「궁시장 김박영」, 위키백과 각궁
- [줄 3] 弓の外側(背)に引張に強い腱を、内側(腹)に圧縮に強い角を配置する — 確認 / EN Wikipedia, Composite bow
- [줄 4] 角弓は同じ張力に対して威力が大きく射程が長い(角弓150~300m、2mを超える和弓は数十m) — 確認 / 국가유산진흥원 「궁시장 김박영」
- [줄 5] 朝鮮半島に水牛は自生していなかった — 確認 / 팜인사이트, 미래한국
- [줄 6] 黒角弓の中心材料である水牛角は中国・日本・琉球などから全量を輸入した。原産地は東南アジアで、朝鮮後期の経路は長崎(中国船・オランダ船)→対馬→倭館だった — 確認 / 윤유숙, 「조선후기 조선·일본의 동남아시아 산물 교역」, 한일관계사연구 70(2020)
- [줄 8] **明**が水牛角を軍需品に指定し、持ち出しを厳しく禁じた(訂正: 従来の「清」という記述は根拠が未確認) — 訂正 / 구도영, 「16세기 조선 대명 사행무역의 수입품과 그 전개양상」, 국학연구(2017)
- [줄 9] 公式の許容量が成宗代に年50部、16世紀に年200対にとどまり、角弓製作の隘路になった(因果の解釈) — 確認 / 동국대 HK+ 칼럼, 구도영 2017
- [줄 10~11] 世祖代に**琉球国**が水牛2頭を送り、司僕寺が昌徳宮の後苑で飼育させた(訂正: 従来の「日本」という記述は実録の原文と一致しない) — 訂正 / 세조실록 세조 8년(1462) 4월 13일
- [줄 12] 成宗10年(1479)までに司僕寺の水牛は70余頭に増えた。ただし昌慶宮での飼育15年で70余頭は、当時の朝廷が「わずかだ」と見た数である(訂正: 「繁殖はうまくいって」→「歩みは遅く」) — 訂正 / 동국대 HK+ 칼럼, 미래한국, 팜인사이트
- [줄 13] 民間に分与され水原・南陽で飼われていた水牛が人を突いて傷を負わせた(訂正: 「野に放していた」→「民家に渡った」) — 訂正 / 팜인사이트
- [줄 14] その後水牛は島へ送られ、中宗4年(1509)の民間への払い下げで国産化は事実上終わった(根拠なし: 「済州島」と特定する記録は確認できず →「島」に差し替え) — 根拠なし / 팜인사이트, 미래한국
- [줄 15] 鹿の角を使う鹿角弓、黄海道の黄牛の角を使う郷角弓が代用として試みられた — 確認 / 동국대 HK+ 칼럼
- [줄 16] 鹿の角は短く鹿茸の需要とも競合し、黄牛の角も強度が水牛角に及ばず、完全な代替には失敗した — 確認 / 동국대 HK+ 칼럼
- [줄 17] 水牛角の調達のため粛宗20年(1694)に弓角契が創設され、対馬藩との公貿易で日本から輸入した(訂正: 「英祖の時に清が禁じたので契を組んだ」という因果は時期が合わない。また1830年代以降、公貿易による水牛角の輸入は**途絶**し、1832年からは銅3,000斤で代納された) — 訂正 / 문화콘텐츠닷컴 「궁각계의 수우각 무역의 쇠퇴」, 윤유숙 2020

## 읽기

ちょうせんさいきょうのぶきを、ちょうせんはじりきでつくれませんでした。
かくきゅうは、きにうしのけんとつのをかさねてはったゆみです。
そとがわのけんはのび、うちがわのつのはおされてちからをためます。
おかげでおなじちからでひいても、やははるかにとおくへとびました。
もんだいはそのつの。ちょうせんのちにすいぎゅうはいなかったのです。
すいぎゅうのつのは、ちゅうごく・にほん・りゅうきゅうからすべてかうしかありません。
ゆみのしんぞうを、まるごとたこくのそうこにあずけていたわけです。
みんはこれをぐんじゅひんとして、つののもちだしをきびしくきんじます。
かくきゅうをつくれるかどうかは、みんのてのうちにありました。
ちょうせんもだまってはいません。すいぎゅうをじぶんでそだてることにします。
せいそのじだい、りゅうきゅうからしゆう1対をむかえてそだててみます。
あゆみはおそく、せいそうのころにようやく70頭までふえました。
ところがみんかにわたったすいぎゅうが、ひとをついてけがをさせます。
すいぎゅうはしまへおいやられ、こくさんかはそこでおわります。
しかのつのやこうぎゅうのつので、だいようのゆみもためしました。
どれもみじかくよわく、すいぎゅうのつののあなはうまりませんでした。
それでもちょうせんはけいというくみあいをつくり、にほんからつのをかいいれます。
でんとうとよばれるあのゆみは、じつはすうひゃくねんぶんのゆにゅうのさんぶつでした。
