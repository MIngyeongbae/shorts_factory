# 手に取った瞬間、マグカップの値段は2倍になります

- 시드: https://en.wikipedia.org/wiki/Endowment_effect
- 매체 적합성: 適合 — 同じカップ1つに違う値札が2枚貼られる画、カップを握った手と空っぽの手の対比、「2個目のカップ」実験の配置図が、言葉の代わりに論旨を運ぶ
- 핵심 질문: なぜ同じマグカップなのに、売る人が言う値段と買う人が払う値段が2倍も開くのか?
- 핵심 반전: よくある説明は「失いたくないから」だが、失う物が何もない人 — すでにカップを持ったまま2個目を買おうとする人 — も同じように高い値をつけた。犯人は損失ではなく所有らしい
- 보이는 것: カップ1つに貼られる2枚の値札、手に入った瞬間に跳ね上がる値段、所有者に2個目のカップを差し出す場面、無料お試し・無料返品のボタン
- 차별점: この実験の有名な解説(損失回避)が後続の実験に挑戦されたという、教養書があまり踏み込まない一段下
- 여운: あなたの部屋の物も、2倍ほど膨らんでいます

## 대본

どうして自分のモノは、他人がつける値段よりいつも高いのでしょう。
カーネマンのチームが、コーネル大の学生の半分にマグカップを配りました。
もらった側には、いくらなら売りますかと聞きました。
もらえなかった側には、いくらまで払えますかと聞きます。
結果はこうです。売値が買値の、ほぼ2倍。
バスケの4強のチケットだと、差は14倍でした。
同じ品物です。違うのはただ一つ、今それが自分の手にあるか。
最初の説明はこうでした。失う痛みは、得る喜びより大きい。
ところが、ここで少し奇妙な追加実験が登場します。
カップを持っている人に、2個目はいくらで買いますかと聞きました。
この人に失うものはありません。それでも高い値をつけました。
犯人は損失ではなく、所有そのものだと見られています。
自分のものになった瞬間、カップは持ち物から自己紹介に変わるというのです。
一方、売る側はカップを守る理由から思い浮かべ、
買う側は逆に、財布を守る理由から思い浮かべます。
無料お試しと無料返品が、あれほど多い理由がここにあります。
使ってみた瞬間、それはもう自分のものになるからです。
マグカップの値札は、カップではなく、握った手のひらに貼られていました。

## 주장

- [줄 1] 愛着が生まれる理由がない物や、数分前に手にしたばかりの物でも、売値(WTA)が買値(WTP)より高くなる — 확인 (Endowment effect 도입부)
- [줄 2] ダニエル・カーネマン、ジャック・クネッチ、リチャード・セイラーがコーネル大の学部生にマグカップを配る実験を行った (1990) — 확인 (Examples 절 / KKT 1990 JPE 98:1325)
- [줄 2] カップは全員ではなく、交互に座った学生の半分にだけ配られた (カップの価値は約$6) — 확인 (KKT 1990)
- [줄 3] カップを所有することになった参加者に「いくらもらえば売るか」(willingness to accept)を尋ねた — 확인 (Examples 절)
- [줄 4] カップをもらわなかった参加者に「いくらまで払うか」(willingness to pay)を尋ねた — 확인 (Examples 절 / 도입부)
- [줄 5] 所有者が要求した額が、非所有者の支払意思額の約2倍だった (中央値$5.25 対 $2.25〜2.75) — 확인 (Kahneman, Knetsch & Thaler 1990)
- [줄 6] ジブ・カーモンとダン・アリエリーの研究で、NCAAファイナルフォーのチケットの仮想売値が仮想買値の約14倍だった (中央値$2,411 対 $175) — 확인 (Carmon & Ariely 2000)
- [줄 7] 2つの群の違いは物ではなく所有の有無だけ (ランダム割当) — 확인 (도입부 valuation paradigm)
- [줄 8] この差の最初かつ主要な説明は損失回避であり、同じ大きさの利得より損失を大きく感じるというプロスペクト理論に基づく — 확인 (Loss aversion 절)
- [줄 9~10] モアウェッジ・シュー・ギルバート・ウィルソン(2009)は、カップを1つもらった参加者に「2個目をいくらで買うか」を尋ねた — 확인 (Connection-based 절 / JESP 원문)
- [줄 11] この「所有者-買い手」は売る立場ではないのに「所有者-売り手」と同じくらい高く評価し、カップをもらわなかった買い手より高かった — 확인 (같은 절)
- [줄 12] 損失回避ではなく所有が原因である — 유력설 (손실 회피가 여전히 선도 설명이고 심리적 관성·기준 가격·질의 이론 등 경쟁 가설 존재) → 줄 12는 이미 추정 표현, 유지
- [줄 13] 所有した物が所有者の自己概念に取り込まれ、アイデンティティの一部になるという愛着理論 — 유력설 (여러 경쟁 이론 중 하나) → "바뀐다는 거죠"로 완화
- [줄 14~15] ジョンソン・ホイブル・ケイナン(2007): 買う予定の人は金を守る理由を、売り手はカップを守る理由を先に思い浮かべた — 확인 (Biased information processing 절)
- [줄 14] この想起順序が「所有=自己」理論の帰結だという因果 — 근거 없음 (질의 이론은 소유가 아닌 질의 순서를 원인으로 보는 별개 설명) → 연결어 "그래서" → "한편"
- [줄 16~17] 無料お試しと無料返品は、所有感を作って解約・返品を減らすマーケティング手段として使われる — 확인 (Implications > Business)

## 읽기

どうしてじぶんのモノは、たにんがつけるねだんよりいつもたかいのでしょう。
カーネマンのチームが、コーネルだいのがくせいのはんぶんにマグカップをくばりました。
もらったがわには、いくらならうりますかとききました。
もらえなかったがわには、いくらまではらえますかとききます。
けっかはこうです。うりねがかいねの、ほぼ2倍。
バスケの4強のチケットだと、さは14倍でした。
おなじしなものです。ちがうのはただひとつ、いまそれがじぶんのてにあるか。
さいしょのせつめいはこうでした。うしなういたみは、えるよろこびよりおおきい。
ところが、ここですこしきみょうなついかじっけんがとうじょうします。
カップをもっているひとに、2個目はいくらでかいますかとききました。
このひとにうしなうものはありません。それでもたかいねをつけました。
はんにんはそんしつではなく、しょゆうそのものだとみられています。
じぶんのものになったしゅんかん、カップはもちものからじこしょうかいにかわるというのです。
いっぽう、うるがわはカップをまもるりゆうからおもいうかべ、
かうがわはぎゃくに、さいふをまもるりゆうからおもいうかべます。
むりょうおためしとむりょうへんぴんが、あれほどおおいりゆうがここにあります。
つかってみたしゅんかん、それはもうじぶんのものになるからです。
マグカップのねふだは、カップではなく、にぎったてのひらにはられていました。
