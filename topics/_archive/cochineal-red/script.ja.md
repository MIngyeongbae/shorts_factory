# コチニール — 銀の次に高かった赤、その正体は虫だった

- 시드: https://en.wikipedia.org/wiki/Cochineal
- 매체 적합성: 適合 — サボテンに付いた白い斑点をこすって赤くにじむ手、乾いた虫の山、枢機卿の赤い服とイギリス軍将校の軍服、オーストラリアを覆うサボテンの地図、口紅の成分表示まで、画面がそのまま説明になる
- 핵심 질문: ヨーロッパ全体が銀に次ぐ高値で買い集めた赤い粉の正体は何だったのか
- 핵심 반전: その赤は染料として存在した色ではなく、虫が食べられないように体内に抱えた防御物質だった
- 보이는 것: 白い蝋 → こする → 赤い染みへと転じる色の反転、そしてその色がアステカの貢納袋からヨーロッパ王室の服を経て今日の成分表示へ移っていく経路
- 차별점: 色の歴史ではなく、虫一匹の生存化学が帝国貿易・スパイ・オーストラリアの生態災害まで引きずり込む連鎖

## 대본

銀の次に高い輸出品が、赤い粉。信じられますか？
スペインはその産地を300年近く独占しました。
サボテンに付いたカビのような白い斑点、こすると手が真っ赤になります。
白いのは蝋の鎧で、中身は濃い紫色の虫なんです。
名前はコチニール。サボテンの汁を吸って生きる、米粒ほどの虫です。
ところがこの赤、もともとの色ではなく武器でした。
カルミン酸という防御物質を、天敵がひどく嫌がるからです。
食べるなと虫が抱えた色を、人間は服にして着たわけです。
アステカの税だったこの虫が、枢機卿の服とイギリス軍将校の軍服を染めます。
ただ、1ポンド作るには虫7万匹を乾かす必要がありました。
そこで1777年、フランスの学者が医者を装って虫を盗み出します。
イギリスは1788年、サボテンごとオーストラリアへ運びますが、虫は全滅でした。
生き残ったサボテンが、オーストラリア東部26万平方キロメートルを覆いました。
価格を崩したのはスパイではなく、19世紀の人工染料でした。
その赤は今、口紅といちごミルクのラベルに残っています。
成分表示のE120、かつて銀に次いで高かった虫の色です。

## 주장

- [줄 1] カルミン(コチニール染料)は植民地期、その地域で銀に次ぐ高価な輸出品であり、アムステルダムの商品取引所は1589年から相場を記録した — 위키백과 Cochineal, "Colonial production export" — 확인
- [줄 2] コチニールは1520年代に新大陸からスペインへ入り、スペインは生きた虫の持ち出しを禁じ輸入港を統制して産地独占を保った。1777年の密輸が定着に失敗した後もメキシコの独占は無傷で残り、1810〜1821年のメキシコ独立戦争を経てようやく終わった(「300年近く」はこの2時点の概算) — "Etymology", "Production elsewhere" — 확인
- [줄 3] 幼虫が体に分泌する白い蝋のため外見は白や灰色に見えるが、体内では赤い色素を作るため濃い紫色である — "Life cycle" — 확인
- [줄 4] 白い蝋は水分の損失と強い日差しを防ぐ保護膜である — "Life cycle" — 확인
- [줄 5] Dactylopius coccus はオプンティア(ウチワサボテン)に付いて汁と養分を吸うカイガラムシで、メスは無翅、体長は約5mm — 문서 첫 문단, "Life cycle" — 확인
- [줄 6~7] コチニールが作るカルミン酸は他の昆虫による捕食を抑える物質で、乾燥した虫の重量の約17〜24%を占める — 문서 첫 문단 / Eisner et al., Science 208:1039(1980) はカルミン酸がアリの摂食を強く抑制することを実験で確認 — 확인 (実証された範囲は昆虫の捕食者)
- [줄 8] 赤い色素分子(カルミン酸)そのものが食べられないための忌避物質であるという事実に基づく解釈の文 — 新しい事実主張はない。色素は白い蝋に覆われて外に露出しないため、視覚的な「警告色」(アポセマティズム)という記述は根拠がなく削除した
- [줄 9] アステカに征服されたオアハカのコイシュトラウアカ地域の11の村が、毎年、装飾綿ブランケット2000枚とコチニール40袋を貢納した / 1464年に教皇パウルス2世が枢機卿の服色を赤に変え(シード記事の「1454年」は誤記 — パウルス2世の在位は1464〜1471年)、1558年ごろその赤い服はアメリカ産コチニールで染められた / 1600年代のイギリス「レッドコート」のうちコチニール染めは将校の軍服であり、兵卒のコートはアカネ染めだった — "Pre-Columbian dye", "Colonial production export", 위키백과 Purple·Red coat (military uniform) — 확인 2건 / 정정 2건
- [줄 10] コチニール染料1ポンド(0.45kg)を作るのに約7万匹が必要で、虫は手で払い落とすかブラシで掃き集めてから乾かす — "Preparation", "Farming" — 확인
- [줄 11] 1777年、フランスの植物学者ニコラ=ジョゼフ・ティエリ・ド・メノンヴィルが植物採集をする医師を装い、コチニールとサボテンの葉をサン=ドマングへ密輸した(持ち出しは成功したが現地での定着に失敗し、メキシコの独占はそのまま残った) — "Production elsewhere" — 확인
- [줄 12] 1788年、アーサー・フィリップがブラジルからコチニールの付いたサボテンをオーストラリアへ持ち込み染料産業を試みたが、ブラジル産のコチニールはまもなく死んだ — "Failed farming in Australia" — 확인
- [줄 13] 生き残ったサボテンはオーストラリア東部の約10万平方マイル(259,000km²)に広がり、1920年代に南米産の蛾 Cactoblastis cactorum を導入して制御した — "Failed farming in Australia" — 확인
- [줄 14] 19世紀半ばにアリザリン・クリムゾンなどの人工染料が登場してコチニールの需要が急落し、スペインの主要産業が事実上消滅する経済的衝撃があった — "Competition from artificial dyes" — 확인
- [줄 15] カルミンは今日、ヨーグルト・乳製品・飲料などの食品着色料や、口紅などの化粧品に使われ、EU承認の食品添加物番号はE120である — 문서 첫 문단, "Modern uses", 위키백과 Carmine — 확인
- [줄 16] 줄 1・줄 15の主張を振り返る文 — 같은 출처 — 확인

## 읽기

ぎんのつぎにたかいゆしゅつひんが、あかいこな。しんじられますか？
スペインはそのさんちを300年ちかくどくせんしました。
サボテンについたカビのようなしろいはんてん、こするとてがまっかになります。
しろいのはろうのよろいで、なかみはこいむらさきいろのむしなんです。
なまえはコチニール。サボテンのしるをすっていきる、こめつぶほどのむしです。
ところがこのあか、もともとのいろではなくぶきでした。
カルミンさんというぼうぎょぶっしつを、てんてきがひどくいやがるからです。
たべるなとむしがかかえたいろを、にんげんはふくにしてきたわけです。
アステカのぜいだったこのむしが、すうききょうのふくとイギリスぐんしょうこうのぐんぷくをそめます。
ただ、1ポンドつくるにはむし7万匹をかわかすひつようがありました。
そこで1777年、フランスのがくしゃがいしゃをよそおってむしをぬすみだします。
イギリスは1788年、サボテンごとオーストラリアへはこびますが、むしはぜんめつでした。
いきのこったサボテンが、オーストラリアとうぶ26万へいほうキロメートルをおおいました。
かかくをくずしたのはスパイではなく、19世紀のじんこうせんりょうでした。
そのあかはいま、くちべにといちごミルクのラベルにのこっています。
せいぶんひょうじのE120、かつてぎんについでたかかったむしのいろです。
