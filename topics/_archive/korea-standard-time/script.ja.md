# 韓国の正午は、なぜ日本の明石市が決めるのか

- 시드: https://namu.wiki/w/한국%20표준시
- 매체 적합성: 適合 — 地図上に引いた東経120度・127.5度・135度の3本の線と朝鮮半島の位置、1908・1912・1954・1961年と基準線が動き回る年表、ソウルと東京の日の出時刻の対比が、そのまま理解を支える
- 핵심 질문: なぜ韓国の時計の基準線は、韓国の国土ではなく日本の兵庫県明石市を通るのか
- 핵심 반전: 他国の基準線を使うのは損に見えるが、そのおかげで韓国はサマータイムなしに1年中30分ぶんの夕方の光をおまけで使っている
- 보이는 것: 基準線が朝鮮半島の外へ押し出されていく動き、時計の針と太陽の位置が30分ずれる対比、同じ時刻のソウルと東京の窓の外の明るさの違い
- 차별점: 四柱推命で30分を引く慣習、在韓米軍の作戦上の都合が押し切った1961年の再変更 — 時計ひとつに地理・歴史・生活リズムが重なっている

## 대본

今、韓国の時計が指すこの時刻。基準は韓国にありません。
韓国の時計の基準線は、日本の兵庫県明石市を通ります。
世界標準時で測ると、ソウルの本当の時刻は8時間28分です。
つまり韓国の時計は、太陽より30分ほど先を走っています。
だから四柱推命では、生まれた時刻から30分引くことが多いんです。
元は違いました。1908年、大韓帝国の勅令が基準線を定めます。
東経127.5度、チョンジュとスンチョンを通る朝鮮半島の真ん中の線。
ところが1912年、朝鮮総督府が日本と同じ135度に変えます。
1954年、イ・スンマン政権が戻しますが、7年後にまた元通り。
今度は在韓米軍の作戦上の都合が大きかったといいます。
では韓国は、他人の時計をはめて損をしているだけでしょうか。
時計が30分進んでいれば、日の出も日の入りも30分遅くなります。
遅刻が怖くて、時計をわざと進めておく人と同じですね。
サマータイムがなくても、夏の夕方はその分長く明るいんです。
代わりに冬の朝が代償です。東京が明るい頃、ソウルはまだ真っ暗。
だから今日も、韓国の正午を決めるのは明石市なんです。
奪われた30分であり、おまけにもらった夏の夕方でもあります。

## 주장

- [줄 1~2] 韓国標準時(UTC+9)の基準子午線である東経135度は朝鮮半島ではなく日本を通っており、その線が通る都市のうち兵庫県明石市が「時のまち」として代表される — 확인 — https://ja.wikipedia.org/wiki/日本標準時子午線 · https://www.am12.jp/135-jstm/
- [줄 3] ソウル(東経127度)の平均太陽時による時刻はUTC+8:28である — 확인 — https://ko.wikipedia.org/wiki/한국_표준시
- [줄 4] 韓国の時計はソウルの平均太陽時より約32分(子午線の間隔では正確に30分)進んでおり、年間を通じて30分のサマータイムに準じる効果がある。台本は「30分ほど」と表記 — 정정 반영 — https://ko.wikipedia.org/wiki/한국_표준시
- [줄 5] 四柱推命の実務で生まれた時刻から30分引く補正は多数派の慣習だが全流派共通の規則ではなく、1954〜1961年生まれは当時の標準時がすでにUTC+8:30のため対象外。台本は「多い」と緩和 — 정정 반영 — https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002985374
- [줄 6] 1908年4月1日、大韓帝国勅令第5号(官報第3994号)で東経127.5度(GMT+08:30)を初めて採用した。ただし乙巳条約後の統監府体制下の決定であり、統監府は1906年から所属官庁に日本標準時を使うよう指示していたため「自ら選んだ」という表現は削除 — 정정 반영 — https://ko.wikipedia.org/wiki/한국_표준시 · https://www.newstopkorea.com/news/articleView.html?idxno=708
- [줄 7] 東経127.5度線は加平・楊平・利川・清州・錦山・鎮安・南原・求礼・順天など朝鮮半島の中央部を貫く — 확인 — https://ko.wikipedia.org/wiki/동경_127.5도
- [줄 8] 1912年1月1日、朝鮮総督府官報第367号(告示第338号)で日本と同じ東経135度(GMT+09:00)に変更された — 확인 — https://ko.wikipedia.org/wiki/한국_표준시
- [줄 9] 1954年3月21日、大統領令第876号で127.5度(GMT+08:30)に戻し、1961年8月10日0時(法律第676号、8月7日公布・国家再建最高会議)に再び東経135度へ — 확인 — https://www.khan.co.kr/article/201008092147425 · https://ko.wikipedia.org/wiki/한국_표준시
- [줄 10] 1961年の再変更の公式な理由は「航空・航海・天文・気象など観測上の不合理」だったが、決定的に働いたと伝えられるのは、在日米軍と在韓米軍の時差で作戦に支障が出るとした在韓米軍側の要求である — 정정 반영 — https://www.khan.co.kr/article/201008092147425
- [줄 12] 標準時をUTC+08:30に変えると日の出・日の入りの時刻はどちらも30分早まる。つまり現行のUTC+9ではその分だけ遅く昇り遅く沈む(ソウルの夏至 05:11/19:57 → 04:41/19:27) — 확인 — https://api.sunrise-sunset.org/json?lat=37.5665&lng=126.9780&date=2026-06-21&tzid=Asia/Seoul&formatted=0 · https://astro.kasi.re.kr/life/pageView/6
- [줄 14] 韓国はすでに平均太陽時より進んだ時間帯を使っており、サマータイムなしでも事実上の日光節約効果を得ている — 확인 — https://www.newstopkorea.com/news/articleView.html?idxno=708
- [줄 15] 同じ冬の朝の時刻に東京はすでに明るく、ソウルはまだ暗い(冬至の日の出は東京06:45/ソウル07:41、56分差)。ソウルと東京は経度が約12.7度違い、南中が約51分ずれる — 확인 — https://api.sunrise-sunset.org/json?lat=35.6895&lng=139.6917&date=2026-12-21&tzid=Asia/Tokyo&formatted=0 · https://api.sunrise-sunset.org/json?lat=37.5665&lng=126.9780&date=2026-12-21&tzid=Asia/Seoul&formatted=0
- [줄 16~17] 現行の韓国標準時は東経135度基準のUTC+9で、日本統治期に導入された基準である。ただし60年余り維持している理由は、残滓の清算不足よりも、30分単位の時間帯を使う国が世界で5%未満という国際慣例と、事実上のサマータイム効果という現実論だと評価される — 확인 — https://ko.wikipedia.org/wiki/한국_표준시 · https://www.newstopkorea.com/news/articleView.html?idxno=708

## 읽기

いま、かんこくのとけいがさすこのじこく。きじゅんはかんこくにありません。
かんこくのとけいのきじゅんせんは、にほんのひょうごけんあかししをとおります。
せかいひょうじゅんじではかると、ソウルのほんとうのじこくは8時間28分です。
つまりかんこくのとけいは、たいようより30分ほどさきをはしっています。
だからしちゅうすいめいでは、うまれたじこくから30分ひくことがおおいんです。
もとはちがいました。1908年、だいかんていこくのちょくれいがきじゅんせんをさだめます。
とうけい127.5度、チョンジュとスンチョンをとおるちょうせんはんとうのまんなかのせん。
ところが1912年、ちょうせんそうとくふがにほんとおなじ135度にかえます。
1954年、イ・スンマンせいけんがもどしますが、7年ごにまたもとどおり。
こんどはざいかんべいぐんのさくせんじょうのつごうがおおきかったといいます。
ではかんこくは、たにんのとけいをはめてそんをしているだけでしょうか。
とけいが30分すすんでいれば、ひのでもひのいりも30分おそくなります。
ちこくがこわくて、とけいをわざとすすめておくひととおなじですね。
サマータイムがなくても、なつのゆうがたはそのぶんながくあかるいんです。
かわりにふゆのあさがだいしょうです。とうきょうがあかるいころ、ソウルはまだまっくら。
だからきょうも、かんこくのしょうごをきめるのはあかししなんです。
うばわれた30分であり、おまけにもらったなつのゆうがたでもあります。
