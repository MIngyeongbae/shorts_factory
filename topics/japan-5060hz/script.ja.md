# 橋を1本渡ると電気が変わる国

- 시드: https://ja.wikipedia.org/wiki/商用電源周波数
- 매체 적합성: 適合 — 日本地図の東西の色分け、街の真ん中を切る川、4か所の変換所を通る細い電力の流れが、すべて理解を支える
- 핵심 질문: なぜ1つの国に電気が2種類あり、なぜ今も統一できないのか
- 핵심 반전: 地形や政策が引いた線ではなく、1890年代に2つの会社がドイツ製・アメリカ製の発電機をそれぞれ買った結果が固まった線である
- 보이는 것: 富士川を境に分かれる東西の色面、川1本を挟んだ同じ街、2011年の東側の停電と西側の余った電気、その間をつなぐ4か所の細い変換所
- 차별점: 国境ではなく1つの街の真ん中を川が切り、左岸と右岸で電気が違う

## 대본

橋を1本渡ると、電気が変わる街があります
静岡県の富士川が、街の真ん中を分けています
川の東は50ヘルツ、西は60ヘルツです
1秒に何回波打つか、それがヘルツです
拍子の違う2曲を重ねるようで、混ざりません
なぜ1つの国に拍子が2つも生まれたのでしょう
1895年、東京電燈がドイツ製の発電機を入れます
その機械の拍子が50ヘルツ、東京の基準です
一方、大阪電灯はアメリカ製の60ヘルツ
2社が周りを飲み込んで広がり、その線でぶつかります
山脈ではなく、発電機2台が引いた線だったのです
2011年、東日本大震災でこの線が足かせに
西に電気が余っても、少ししか送れませんでした
拍子を変える変換所は、今も全国に4か所だけ
いっそ60ヘルツに統一すればいいのでは
政府の試算では10兆円、工事は40年以上
統一ではなく、変換所を増やす道を選びました
富士川の橋を1本渡れば、そこはまだ1895年です

## 주장

- [줄 1~2] 静岡県富士市・富士宮市は、商用電源周波数の境界である富士川が市内を横切り、左岸は50Hz・右岸は60Hzが混在する — 확인 「50 Hzと60 Hzの境界線」
- [줄 3] 最も有名な境界は静岡県の富士川であり、川を境に東が50Hz、西が60Hzである — 확인 「50 Hzと60 Hzの境界線」
- [줄 4] 商用電源周波数とは、商用電源として供給される交流電源の周波数(1秒あたりの振動回数)を指す — 확인、文書の定義部
- [줄 5] 周波数の異なる系統同士は直接融通できず、50Hz↔60Hzの周波数変換所を経る必要がある — 확인 「東西間での周波数変換による相互融通」
- [줄 6~8] 東京電燈が交流への転換を決めて50Hz仕様のドイツAEG製発電機を導入し、**1895年9月20日に浅草火力発電所の使用を開始した**(1893年は着工年)。以後、関東は交流50Hzに統一されていった — 정정 반영 「浅草火力発電所」/「東京電燈」。シード本文の「1893年稼働」は着工と稼働の混同
- [줄 7 배경] 浅草発電所は国産の石川島造船所製200kW単相交流(2,000V・100Hz)4台と、ドイツのアルゲマイネ(現AEG)製265kW三相交流(3,000V・50Hz)2台を併せ持っていた — 확인 「浅草火力発電所」(本文未使用、반전 소재)
- [줄 9] 大阪電灯はアメリカ製の60Hz発電機を採用した — 확인 「日本の商用電源周波数」。ただし「1888年の設立直後からGE製60Hz」は정정:1889年の開業当時はトムソン・ヒューストン製1,150V交流であり、60Hz・2,300Vは1890年代後半〜1900年に定着 「大阪電灯」
- [줄 10] この2つの軸を中心に各地の電力供給が次第に集約された結果、東西の周波数差が形成された — 확인 「日本の商用電源周波数」
- [줄 11] 境界はおおむね糸魚川-静岡構造線に沿う形だが、原因は地形ではなく明治期の東京電燈・大阪電灯の発電機導入の選択である(地形は結果的な一致、因果は発電機) — 확인 「50 Hzと60 Hzの境界線」/「日本の商用電源周波数」
- [줄 12~13] 2011年の東日本大震災と発電所停止で電力不足が発生し、東京電力が計画停電を実施した。東西で周波数が異なり融通できる電力が少なかったことが、電力不足の一因だった。当時の変換能力は3か所合計100万kW(佐久間30万・新信濃60万・東清水10万)、東京電力の不足見通しは約1,000万kW — 확인 「東西間での周波数変換による相互融通」/「佐久間周波数変換所」
- [줄 14] 電力会社間の融通用の周波数変換所は佐久間・新信濃・東清水・飛騨(新信濃)の4か所であり、2021年3月時点の東西間の最大融通電力は210万kWである。2026年現在も4か所のままで、300万kWへの増強は2027年度を目標に工事中 — 확인 「東西間での周波数変換による相互融通」/経済産業省資料
- [줄 15~16] 2011年以降の政府シミュレーションでは、50Hz地域をすべて60Hzに変える場合、設備更新費が約10兆円、発電設備の周波数変更工事の期間は40年以上と試算され、日本政府は「周波数の統一は非現実的」と判断した — 확인 「日本の商用電源周波数」および経済産業省試算(2012年3月)
- [줄 17] 統一の代わりに周波数変換所を置いて連系する方式が現実的とされ、2013年2月に東清水30万kWの本格運用、2021年3月に飛騨信濃90万kWの運用開始で、融通容量は120万kWから210万kWに増えた — 확인 「東西間での周波数変換による相互融通」
- [줄 18] 1895年の浅草火力発電所の使用開始(東京電燈50Hz)が、今日の境界の起源である — 정정 반영 「浅草火力発電所」
