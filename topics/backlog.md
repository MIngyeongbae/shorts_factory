## 발굴 메모 (2026-08-10)

각 후보의 7단 대응. **여기 적힌 사실은 발굴 단계의 가설이다** — 근거 확정은 `[0b]`가 스펙 06의
사료 우선순위로 다시 한다 (나무위키·위키백과는 힌트로만 썼다).

### 조선 금속활자 갑인자
- 뒤집기: "조선 금속활자는 처음부터 뛰어났다" → 첫 활자 계미자(1403)는 하루 몇 장이 한계인 실패작
- 실패 대안 ①: 밀랍으로 활자를 판에 고정 → 인쇄 중 활자가 흔들림
- 실패 대안 ②: 경자자(1420)로 활자를 작고 고르게 → 여전히 밀랍 고정이라 한계
- 발상 전환: 밀랍을 없애고 **식자판 조립 + 죽목으로 빈틈 메우기** (갑인자, 1434)
- 숫자: 1403 / 1420 / 1434, 하루 몇 장 → 40여 장, 능률 약 2배
- 현재 접점: 청주 고인쇄박물관, 국립중앙박물관

### 석빙고
- 뒤집기: "석빙고는 조선의 첨단 냉장 기술" → 정작 **수도 서울의 국영 빙고는 끝까지 나무였다.**
  석빙고는 지방에만 남았다
- 실패 대안 ①: 목빙고·초개빙고 → 매년 수리에 목재·인력 소모가 큼
- 실패 대안 ②: 영조·정조 때 돌로 고쳐 짓자는 논의 여러 차례 → 석재·재력 부족으로 중앙은 무산
- 숫자: 18세기 등장, 현존 7기, 지방 빙고 31개소, 배수로 5도 경사
- 현재 접점: 경주·안동·창녕·청도·현풍·영산 석빙고 현존

### 조선왕조실록 사고
- 뒤집기: "국가 최고 기록물은 왕궁에서 엄중히 보관" → 최종적으로 **산속 절에 맡기고 승려가 지켰다**
- 실패 대안 ①: 도성 춘추관 + 평지 도시 3사고(충주·성주·전주) → 1592 임진왜란에 전주만 생존
- 실패 대안 ②: 1606년 5사고로 산에 분산 → 이괄의 난(1624)·병자호란(1636)에 춘추관본 소실,
  마니산은 1653년 화재
- 발상 전환: 접근성을 버리고 오지로. 정족산·태백산·적상산·오대산 + 수호 사찰
- 숫자: 3사고 → 5사고 → 4사고, 1592 / 1606 / 1653 / 1660
- 현재 접점: 오대산 사고·정족산 사고 복원지

### 검토 후 제외
- **한지 제조**: 공정은 풍부하나 "쉬운 방법이 왜 실패했는지"의 사료가 약해 3~4단을 못 채운다
- **팔만대장경**: 너무 유명해 통념 뒤집기가 약하고, 바닷물 담금설은 근거 논란이 있어 그라운딩 위험

### 레퍼런스 채널 중복 확인 (부분)
`@60chtptkd` 최근 15편을 확인했다. 현재는 **현대 건축·설비 쪽**이다 — 아파트 층간소음·단열·환기,
에어컨, 인천대교, 해운대 잠제. 조선 계열은 궁궐 마당, 북악산 성벽, 한강 배다리 정도다.
위 후보 3건은 이 15편에 없다.

전체 대조는 안 된 상태다. 특히 석빙고는 구조물이라 겹칠 여지가 남는다 — `[0b]`의 비판 세션이
