# ADR-0009: 인간 게이트를 토픽 패키지(조사~대본) 완성 후 go/no-go로 둔다

- 상태: 승인
- 날짜: 2026-08-07
- 관련 스펙: specs/06-topic-research.md, specs/05-pipeline.md
- 관계: ADR-0007의 "검수 지점 = 팩트시트"를 확장·대체 (그라운딩 규칙 자체는 유지)

## 맥락

LLM 단계는 구독으로 한계비용 0 (ADR-0008), 비주얼 단계는 편당 ~$7. 비용 절벽이 대본과 이미지 사이에 있으므로, 텍스트로 가능한 모든 품질 작업(조사·검증·비판·대본·스코어링)을 절벽 앞에서 끝내는 것이 최적이다. 또한 사람의 go/no-go 판단은 팩트시트(중간 산출물)보다 완성 대본(최종 형태)을 보고 할 때 정확하다.

## 결정

- 소재당 `topics/{slug}/` 폴더에 조사→검증→비판→팩트시트→대본 후보→선발본을 순차 생성 (토픽 패키지)
- 조사/검증/비판은 **독립된 헤드리스 세션**으로 실행 (자기 검증 오염 방지: 비판 세션에는 앞 세션의 결론이 아닌 원자료를 제공)
- 인간 게이트는 패키지 완성 후 1회: STATUS.md에 go / no-go / 보류 기록. **go 판정 전에는 비주얼 파이프라인([3. tts] 이후) 진입 금지**
- 일일 패키지 생산량 1~5개, 승인률은 목표를 두지 않음 (까다로울수록 변동비 효율 상승)

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| 팩트시트 시점 검수 (기존 ADR-0007) | 검수 대상 짧음 | 소재의 최종 가치를 추상적으로 판단해야 함 | 대본 생성이 공짜라 절벽 앞까지 미는 게 이득 |
| 완전 무인 (스코어러만으로 go) | 손 안 감 | 스코어러 미검증 상태에서 $7 자동 지출 | 조회수 데이터로 스코어러 보정 후 v2에서 재검토 |

## 결과

- 파이프라인이 2부로 분리: 1부(패키지 생산, 무료·자동) / 2부(영상 생산, 유료·승인 필요)
- STATUS.md의 no-go 사유가 축적되면 스코어러 루브릭·소재 4조건의 보정 데이터가 됨
- 되돌릴 조건: 스코어러 예측과 실제 조회수의 상관이 검증되면 go 판단의 부분 자동화(사전 승인 조건부 자동 진행) 재검토
