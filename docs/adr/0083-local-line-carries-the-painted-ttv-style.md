# ADR-0083: `local` 라인이 `art`의 검증된 회화체 `ttv_style`을 그대로 진다 — 라인 간 차이를 **프레임 유무 하나**로 좁힌다

- 상태: **승인** (2026-08-30, 사람 — "승인할게")
- 날짜: 2026-08-30
- 관련 스펙: specs/schema/vocab.json (`meta.video_line.local`), specs/03-visual-rules.md, specs/05-pipeline.md
- 관련 ADR: **개정** — ADR-0059(라인 = 어댑터 + 라인 값 몇 개), ADR-0070·0075(라인이 자기 룩을
  지고 엔진마다 말이 다르다). **유지** — ADR-0034(값은 schema에서 로드, 출처는 하나),
  ADR-0072 결정 5(한 라인 안에서 씬이 엔진을 고른다)

## 맥락

### 1. MJ가 막혀 `local`로 내려왔는데, 룩이 앵커와 무관하다

2026-08-30 미드저니 계정이 CF 사람 인증(캡차)에 걸려 사용 불가가 됐고(15:47·19:27 두 번,
사람이 풀지 못함), 남은 3편(후지산·1만 년 경고·화분증)을 `local` 라인으로 돌리기로 했다
(judgment/human.json 라인 변경, 같은 날).

그런데 `local`은 `ttv_style`이 없어 `vocab.line_style()`이 전역 `meta.style.base_style`로
떨어진다 — *"semi-stylized 3D visualization render sitting halfway between clean low-poly
and photoreal"*. **이 편들만 3D 룩으로 나오고, 같은 배치의 앞선 8편(회화체)과 결이 갈린다.**

### 2. 앵커 14장은 회화이고, info도 회화다 (실측 2026-08-30)

`엥커래퍼런스/` 14장을 다시 열어 확인했다.

| 앵커 | 무엇으로 그려졌나 |
|---|---|
| 항공 설정샷(교토 가로) | 과슈·수채, 인공 구조물에 자로 그은 실선, 세 겹 후퇴면, 종이 결 |
| 단면 컷어웨이(해식애) | 회화. **절단면만 채도 높은 청록으로 평평하게 분리** |
| 설명 다이어그램(드레이크 해협) | **평면 인포그래픽이 아니다** — 박물관 전시실 벽의 지도 벽화 + 범선 모형 |

즉 **일반 씬과 info 씬의 매체·팔레트·광원이 같다.** 다른 것은 그림의 *내용*이지 *화법*이
아니다 — info는 설명 장치(절단면 색분리·그림 속 지도·축척 인물·셀 수 있는 반복)를 그 회화
안에 세운다. 이것은 이미 `vocab.info_device`가 씬마다 고르는 값이고 스펙 03의
「정보를 무엇이 지는가」가 정한 규칙이다.

### 3. `art.ttv_style`은 이 엔진에서 이미 검증됐다

`art`의 info 씬은 프레임 없이 comfy-h3 텍스트→영상으로 가고 STYLE 절에 `art.ttv_style`을
싣는다 (ADR-0075 결정 1·3). **2026-08-29~30 배치의 완주 8편에서 info 씬 전부가 이 경로로
나왔다** — 온돌 9씬, 에도 소방·천일염·세이칸 등 편당 5~11씬. 강등(`demoted_info`)은 0이었다.
즉 이 문자열은 `local`이 쓸 바로 그 엔진에서 이미 통과한 값이다.

산출물로 확인한 art info 씬 프롬프트의 골격 (`runs/20260830-edo-fire-destruction/prompts.json`
씬 3):

```
FORMAT:  vertical 9:16 + {seconds} + ttv_style(회화체 서술)
STAGING: technical model on a flat neutral pale gray studio ground …
SUBJECT: 설명용 인포그래픽 그 자체 — 공유 베이스 레일 위에 같은 피치로 늘어선
         검은 기둥 두 줄(에도 49 / 교토 9)을 눈으로 세게 하는 물리 모형
CAMERA / ACTION
RED:     빨간 브래킷·라벨 ("Edo 49" · "Kyoto 9" · "267 years")
NEGATIVE
```

**RED는 마지막 한 절이고 본체는 SUBJECT의 인포그래픽이다.** 이 구조는 라인과 무관하게
`[5]`가 만든다 — `local`도 그대로 받는다.

### 4. 그러면 두 라인의 차이가 무엇만 남는가

| | `art` | `local` (이 ADR 뒤) |
|---|---|---|
| 일반 씬 | MJ가 CLEAN 프레임 → 그것을 first로 잇는다. 프롬프트에 STYLE 절 없음 | **프레임 없음.** 프롬프트가 전체 골격(FORMAT·STAGING·CAMERA·NEGATIVE + STYLE) |
| info 씬 | 프레임 없음, comfy-h3 텍스트→영상, `ttv_style` | **완전히 동일** |
| 룩의 출처 | 프레임(MJ) + `ttv_style` | `ttv_style` 하나 |
| 변동비 | MJ 정액 + 로컬 GPU | 로컬 GPU만 (0) |

차이가 **프레임을 입력으로 받는가 하나**로 좁혀진다.

## 결정

`specs/schema/vocab.json`의 `meta.video_line.local`에 **`ttv_style`을 추가한다. 값은
`art.ttv_style`과 글자 그대로 같다** — 같은 앵커에서 나왔고 같은 엔진에서 검증됐으므로 새
문자열을 짓지 않는다. `local`에는 `mj_style`도 `style_in_frames`도 주지 않는다 (MJ를 부르지
않고 프레임을 받지 않는다). info 씬의 설명 장치는 지금처럼 `info_device`와 `[3s]`가 정하고,
스타일 문자열은 그것을 다시 적지 않는다 (ADR-0034 — 출처는 하나).

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| **A. 전역 `base_style`을 회화체로 바꾼다** | 라인마다 안 적어도 된다 | `base_style`은 fal 프로브 15클립으로 검증된 3D 문자열이고, 그것을 쓰는 다른 소비자(`api` 라인·2샷 문구·프로브 기준선)가 같이 흔들린다 | 검증 범위 밖까지 바꾼다. 되돌릴 때 무엇이 원인인지 못 가른다 |
| **B. info 씬 전용 문자열(`ttv_style_info`) 신설 + `visual_rules` 분기** | 일반/info를 문자열로 갈라 쓸 수 있다 | 앵커에 근거가 없다 — 14장에서 두 종류의 매체·팔레트·광원이 같다. 설명 장치는 이미 `info_device`가 정하므로 출처가 둘이 된다 | 근거 없음 + ADR-0034 위반. 코드 분기까지 늘어난다 |
| **C. `local`용 회화체 문자열을 새로 쓴다** | 텍스트→영상 전용으로 다듬을 수 있다 | 검증이 0이다. `art.ttv_style`은 8편 info 씬에서 통과한 값인데 그것을 버리고 미검증 문자열로 시작한다 | 재검증 비용이 이득보다 크다 |
| **D. 그냥 3D(`base_style`)로 간다** | 변경 없음 | 같은 배치 안에서 3편만 결이 다르다. 앵커와 무관한 룩 | 채널 룩이 편마다 갈린다 |

## 결과

**바뀌는 것**

- `specs/schema/vocab.json` — `meta.video_line.local`에 `ttv_style` 1개 키 추가 (+ 왜인지
  적는 `_ttv_style` 주석). 스키마 구조 변경 없음 (`art`가 이미 쓰는 키다)
- 코드 변경 **없음** — `vocab.line_style()`이 라인 이름을 묻지 않고 어휘에서 읽는다 (ADR-0034)
- 스펙 03·05 문장 변경 **없음** — 라인별 값의 정본은 `vocab.json`이고 스펙은 그것을 가리킨다
- 재실행: 라인이 바뀐 3편의 `[5] prompt --force` → `[7] videogen`. 대본·TTS·씬 계약은 재사용.
  **변동비 0** (로컬 GPU만)
- 비용 영향: MJ 호출이 0이 된다 (편당 이미지 10~12장 + 영상 20회 안팎이 빠진다)

**되돌릴 조건**

1. **사람 판독에서 3D 쪽이 낫다고 나오면** — 이 키를 지우면 `base_style`로 자동 복귀한다
   (한 줄 되돌리기)
2. **H3가 프레임 없이 이 회화체를 못 버티면** — info 씬은 8편에서 통과했지만 일반 씬은
   피사체가 무겁다(건축·군중·풍경). 강등·재생성이 편당 5씬을 넘으면 재검토한다
3. **MJ가 복구되면** — 그때는 이 3편의 `video_line`을 `art`로 되돌리고 `[5]`·`[6]`·`[7]`을
   다시 돌리는 것이 원래 룩이다. 이 ADR은 그 경우에도 유지된다 (`local`은 MJ 없이 도는
   라인으로 남는다)
