# ADR-0001: 연출 결정을 LLM 자유 판단이 아닌 비트 기반 룰 테이블로 고정한다

- 상태: 승인
- 날짜: 2026-08-07
- 관련 스펙: specs/02-beat-schema.md, specs/03-visual-rules.md, specs/04-audio-rules.md

## 맥락

원본 채널 3편 실측 분석 결과, 연출 요소(빨간 X, 대형 숫자, 단면 컷, SFX 컷아웃+차임)가 대본의 스토리 비트와 1:1로 대응함이 확인됐다. 예: "발상을 뒤집습니다" 시점에 매 편 오디오 컷+차임, 실패 비트마다 빨간 X. 연출을 씬마다 LLM에게 자유 기술시키면 편차가 크고 토큰 비용이 늘며, 채널 아이덴티티(일관된 룩)가 무너진다.

## 결정

대본의 각 문장에 비트 태그(enum)를 부여하고, 이미지 프롬프트 스타일·오버레이·카메라·SFX·전환을 비트 → 연출 룰 테이블(스펙 03, 04)로 결정한다. LLM의 창의적 판단은 `subject`(피사체 선정)와 대본 내용에만 허용한다.

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| 씬마다 LLM이 연출 자유 기술 | 유연함 | 편차 큼, 비용 증가, 룩 불일치 | 채널 일관성이 핵심 자산 |
| 사람이 씬별 연출 수동 지정 | 품질 통제 | 자동화 목적에 반함 | 비목표 |
| 비트 룰 + 예외 필드 허용 | 유연+일관 | 예외 남용 위험 | v2에서 `notes` 필드로 제한적 수용 |

## 결과

- 연출 로직이 코드(룰 테이블)로 이동 → 테스트 가능, 채널 룩 변경 시 스펙 03/04만 수정
- 되돌릴 조건: 비트 enum으로 커버 안 되는 씬이 편당 3개 이상 반복 발생하면 스키마 확장 재검토
