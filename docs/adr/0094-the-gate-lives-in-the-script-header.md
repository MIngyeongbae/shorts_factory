# ADR-0094: **판정 게이트가 `script.md` 머리로 온다** — 사람은 주석만 푼다, 그리고 2부는 언어별로 고른다

- 상태: **승인** (2026-09-04, 사람 — 형식·의미 전부 사람 지시. *"1부를 시작할지 시작하지
  않을지 정하는게 너무 topics/ 에서보고 찾아서 run에서 확인하고 이러는게 너무 안좋아"*,
  *"한국어 대본 상단에 주석으로 `//reject [ //ko, //ja, //en ]` 이런식으로해서 만들어놔
  그걸 보고 내가 주석만 풀게 그럼 주석 풀린 것만 진행하는걸로해. 그리고 reject 를 주석
  제거하면 그냥 버려지는 토픽으로하자"*)
- 날짜: 2026-09-04
- 관련 스펙: `specs/01-script-template.md`(정본 포맷), `specs/05-pipeline.md`(판단 게이트·
  1부↔2부 경계·`[3]`·`[9]`·`[10]`), `specs/06-topic-research.md`(토픽 패키지),
  `specs/07-judgment-autonomy.md`(판정 스키마)
- 관련 ADR: **개정** — ADR-0009(사람 게이트: 자리가 바뀐다), ADR-0049(판정은 사람이
  `script.md`를 읽고 한다 — 읽는 그 파일에 적는다), ADR-0056 결정 5(ko의 go가 셋의 go였다 —
  이제 언어마다 고른다), ADR-0088(반려 기준). **유지** — ADR-0059 결정 2(`video_line`은
  `judgment/human.json`에 남는다)

## 맥락

### 1. 판정 한 번에 파일 셋을 연다

지금 사람이 편 하나를 판정하려면 ① `topics/{slug}/script.md`를 읽고 ② `judgment/human.json`을
손으로 쓰고 ③ `STATUS.md`를 고친 뒤 ④ 2부를 어디까지 돌렸는지는 `runs/{run_id}/`에서 본다.
2026-09-03에 29편을 판정할 때 사람이 *"일일이 go no-go 쓰기가 힘들어서"* 제목 7개를 대화로
지목했고 스크립트가 `human.json` 29개와 `STATUS.md` 29개를 대신 썼다 — **판정의 정본이
사람이 읽지 않는 파일에 있으니 사람이 직접 못 쓴다.**

### 2. 게이트를 읽는 코드가 없다

`stages/judgment.py`가 `human.json`에서 읽는 값은 `video_line` 하나다. `decision: go`
확인은 *"2부 진입점의 몫"*(`tts.py` 독스트링)이라고 적혀 있는데 그 진입점이 없다 —
`[3] tts`는 대본 파일이 있으면 돈다. 게이트는 지금까지 **절차**였고 코드가 아니었다.

### 3. 언어가 이제 공짜가 아니다

ADR-0056은 *"클립 풀 하나를 셋이 공유"*하므로 ko의 go가 ja·en의 go였다. ADR-0095가 그
전제를 깼다 — 언어마다 클립의 절반을 새로 만들어 언어 하나가 편당 **약 30분의 GPU**가 됐다.
그러면 "이 편을 만들까"와 "어느 언어로 만들까"가 다른 질문이고, 둘 다 사람이 대본을 읽는
그 자리에서 답해야 한다.

### 4. 사람이 형식을 정했다

```
//reject
[
//ko,
//ja,
//en
]
```

주석을 **푸는** 것이 승인이다 — 기본 상태(전부 주석)가 보류이고, 사람이 한 일이 없으면
아무것도 안 돈다. 파일 하나에 판정과 대본이 같이 있으니 사람은 그 파일만 연다.

## 결정

**판정은 `topics/{slug}/script.md` 첫 줄들의 주석 블록이다.** 사람은 그 블록의 주석만 풀고,
파이프라인은 그것만 읽는다.

1. **자리와 꼴.** 파일 **맨 위**, `# 제목`보다 앞이다. 줄은 다섯이고 순서가 고정이다:
   `//reject` · `[` · `//ko,` · `//ja,` · `//en,` · `]` (마지막 언어의 쉼표는 있어도 없어도
   된다). 앞뒤 공백은 무시한다. **`script.md`(ko)에만 있다** — 번안 대본에는 없다.
2. **의미.** `reject`의 주석이 풀리면 **반려**다 — 언어 줄과 무관하게 이긴다. 언어 줄의
   주석이 풀리면 그 언어가 **2부 대상**이다. 아무것도 안 풀렸으면 **보류**다.
   보류인 편은 2부의 어느 단계도 돌지 않는다.
3. **누가 쓰는가.** `[1] draft`가 대본 앞에 블록을 붙인다(전부 주석). `[2] factcheck`가
   정정본을 쓸 때 **블록을 그대로 보존한다** — 세션 산출은 `#`으로 시작하므로 블록이 없고,
   덮어쓰면 판정이 사라진다. **세션은 블록을 보지 않는다** — `[2]`·`[2l]`·`[3s]`·`[5]`가
   대본 전문을 프롬프트에 실을 때 블록을 떼고 싣는다. 사람이 손으로 만든 옛 편에는 블록이
   없고, 그때는 **있는 언어 전부**가 대상이다(옛 편은 이미 판정을 거쳤다).
4. **2부가 읽는 곳.** `judgment.read_gate()` 하나다. `[3] tts`가 2부의 첫 단계로서 **반려·
   보류면 멈춘다**. 언어는 ko + 선택된 언어를 돈다 — ko는 `[3s]`의 줄 경계와 `[7]`의 기본
   풀이 필요해 선택과 무관하게 실측한다 (ADR-0056 결정 5는 그대로다). `[7]`은 선택된
   언어의 겹풀만 만들고(ADR-0095), `[9]`·`[9t]`·`[10]`은 선택된 언어만 돈다. **`--lang`은
   언제나 이긴다** — 명시가 판정보다 세다(디버깅·재조립).
5. **`[10]`의 보관 조건은 "선택된 언어 전부"다.** 있는 언어 전부가 아니다 — 사람이 en을
   안 골랐으면 en이 없는 것이 그 편의 완성이다.
6. **`judgment/human.json`의 `decision`은 폐기한다.** 정본은 머리 블록이고 두 곳에 적지
   않는다 (ADR-0034). `video_line`은 그 파일에 **남는다** — 라인 선택은 편당 한 번도 안
   바꾸는 값이라 대본 머리에 둘 이유가 없다 (ADR-0059 결정 2). 없으면 기본 라인이다.
7. **반려된 편은 보관함으로 간다** (ADR-0088 기준 ②의 신호가 `reject`로 바뀐다).
   옮기는 것은 `tools/backlog_sync.py`다 — 판정을 표(`제작완료`·`반려`)에 비추는 도구라
   반려의 뒷정리(이동)도 거기가 맞다. 옛 `no_go`도 같은 취급이다.
8. **`STATUS.md`의 머리글은 블록의 투영이다** — `reject` → `no-go`, 언어 하나라도 →
   `go`, 아니면 `보류`. 판정을 `STATUS.md`에 적으면 파이프라인은 여전히 읽지 못한다.

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| **A. `human.json`을 그대로 두고 CLI(`judge --go --lang ko,ja`)를 만든다** | 파일 계약이 안 바뀐다 | 사람이 대본을 읽는 자리와 판정하는 자리가 여전히 다르다. 명령을 외워야 한다 | 문제 제기가 "파일을 여러 곳 여는 것"이다 — 자리를 안 옮기면 안 풀린다 |
| **B. `STATUS.md` 머리글을 게이트로 읽는다** | 파일이 이미 있다 | `STATUS.md`는 진행 체크리스트를 코드가 다시 그리는 파일이라 사람의 판정과 기계의 투영이 한 파일에서 싸운다 (`status.py` 독스트링이 그 이유로 둘을 갈라 뒀다). 언어 선택 자리도 없다 | 주인이 다른 두 값을 한 파일에 두는 것이 ADR-0009 이래의 문제였다 |
| **C. 머리 항목 `- 판정: go ko,ja`** | 다른 머리 항목과 같은 꼴 | "쓰는" 형식이다 — 사람이 값을 타이핑해야 하고 오타(`jа`)가 조용히 무시된다 | 사람이 고른 형식은 **지우는** 형식이다(주석 풀기). 오타 자리가 없다 |
| **D. 머리 주석 블록 (채택)** | 사람이 대본을 읽는 파일 그 자리. 기본이 보류라 손 안 댄 편은 안 돈다. 값을 타이핑하지 않는다 | `script.md` 파서가 블록을 알아야 하고, 정정본을 쓰는 `[2]`가 보존해야 한다 | — |

## 결과

### 바뀌는 것

- **`stages/scriptmd.py`** — 블록 파싱(`parse_gate`)·떼기(`strip_gate_block`)·붙이기
  (`render_gate_block`). `parse_script_md`는 블록을 무시한다(옛 파서도 무시했다 — 머리
  `- ` 항목이 아니라서).
- **`judgment.py`** — `read_gate(paths, slug) → Gate(rejected, languages | None)`.
  `read_video_line`은 그대로다.
- **`[1]`** 블록을 붙인다. **`[2]`** 정정본에 블록을 되붙인다. **`[2]`·`[2l]`·`[3s]`·`[5]`**
  프롬프트에 실을 때 뗀다.
- **`[3]`** 반려·보류면 멈춘다. 기본 언어 = ko + 선택. **`[9]`·`[9t]`·`[10]`** 기본 언어 =
  선택 ∩ 있는 것. `[10]` 보관 조건 = 선택된 언어 전부 성공.
- **`status.py`** 게이트 규칙 문구. **`tools/backlog_sync.py`** `반려` ← `reject`, 반려 편
  이동.
- **스펙** 01·05·06·07. CLAUDE.md의 "토픽 하나 = 쇼츠 3편"은 "최대 3편, 사람이 고른 언어만".
- **비용** 0.

### 되돌릴 조건

1. **사람이 블록을 잘못 풀어 편이 통째로 잘못 돈 일이 생기면** — 예: `reject`를 풀려다
   `ko`를 풀었다. 형식이 사람 실수를 부르는 것이므로 확인 단계(`[3]`이 시작 전에 판정을
   되읽어 로그에 크게 찍는다)를 더한다. 지금은 로그 한 줄이다.
2. **`[2]`가 블록을 잃는 경로가 하나라도 나오면** — 정정본 쓰기 외에 `script.md`를 쓰는
   코드가 생겼다는 뜻이다. `write_script_md()` 하나로 모은다.
3. **언어 선택이 늘 셋 다이면** — 언어별 선택이 쓸모없었다는 뜻이고 블록을 두 줄
   (`//reject`·`//go`)로 줄인다.
