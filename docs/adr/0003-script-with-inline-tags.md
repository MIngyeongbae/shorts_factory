# ADR-0003: 대본과 비트 태그를 단일 LLM 호출로 동시 생성한다

- 상태: 승인
- 날짜: 2026-08-07
- 관련 스펙: specs/01-script-template.md, specs/02-beat-schema.md

## 맥락

비트 태그를 얻는 방법은 (a) 대본 생성 후 별도 분류 호출, (b) 생성 시 태그 동시 출력 두 가지다. 대본 템플릿의 7단 구조가 고정이므로, 문장의 비트는 생성 시점에 이미 결정돼 있다 — 생성 후 다시 분류하는 것은 정보를 버렸다가 복원하는 낭비다.

## 결정

대본 생성 LLM이 씬 JSON 배열(text + beat + emphasis + subject + camera)을 한 번에 출력한다. validate 단계에서 스펙 01 구조 검증과 스펙 02 스키마 검증을 함께 수행하고, 실패 시 사유를 포함해 재생성한다 (최대 3회).

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| 생성 → 별도 분류 2단계 | 단계별 책임 분리 | 호출 2배, 분류 오류 가능성 추가 | 템플릿 고정이라 분류 난이도가 낮아 분리 이득 없음 |
| 태그 없이 휴리스틱 분류 (시그니처 문구 매칭) | 무비용 | 문구 없는 문장의 비트 모호 | 정확도 |

## 결과

- script 단계 출력이 곧 scenes.json 초안 → 파이프라인 단순화
- 되돌릴 조건: 동시 생성 시 대본 품질(스토리 몰입도)이 태그 제약 때문에 저하된다는 정성 평가가 반복되면 2단계 분리 재검토
