# ADR-0008: LLM 단계는 Claude Code 헤드리스(구독 플랜)로 실행한다

- 상태: 승인
- 날짜: 2026-08-07
- 관련 스펙: specs/05-pipeline.md

## 맥락

LLM 텍스트 단계([0b. research]는 웹 검색 포함, [1. script], [1b. score], [5. prompt])를 Anthropic API 종량제로 호출하면 편당 토큰 비용이 발생한다. 생산량이 하루 1~5편으로 낮아 Claude 구독 플랜(Pro/Max)의 사용 한도 내에서 처리 가능하다. 반면 이미지(NB2)·모션(Kling)·TTS(ElevenLabs)는 타사 서비스로 Claude 플랜과 무관하게 별도 과금된다.

## 결정

- LLM 단계는 `claude -p`(헤드리스 모드) 호출로 구현하고 구독 인증을 사용한다. API 키 종량제 경로는 사용하지 않는다
- 출력은 JSON 스키마 강제 (파이프라인 계약 준수)
- 한도(5시간 윈도우/주간 상한) 도달 시: 지수 백오프 대기 후 재개, run 상태에 기록. 파이프라인은 중단이 아니라 지연으로 처리
- 비용 구조: LLM 변동비 = 구독료로 흡수(한계비용 0), 편당 변동비는 비주얼·음성(~$7)만 잔존

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| Anthropic API 종량제 | 한도 없음, SLA 명확 | 편당 비용 추가 | 저생산량에서 구독이 압도적으로 유리 |
| 로컬 LLM (VPS/Mac mini) | 무료 | 대본 품질이 채널 핵심인데 품질 열위 | 훅 품질 = 수익 |

## 결과

- 파이프라인 오케스트레이터(Python 또는 n8n)가 claude CLI를 서브프로세스로 호출하는 구조
- 되돌릴 조건: 생산량 증가로 플랜 한도가 병목이 되거나, 무인 배치의 안정성 요구가 커지면 해당 단계만 API 종량제로 전환 (호출 레이어만 교체되도록 어댑터 패턴 유지)
