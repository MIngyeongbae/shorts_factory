# ADR-0002: 화면 텍스트를 생성 레이어와 합성 레이어로 분리한다

- 상태: 승인
- 날짜: 2026-08-07
- 관련 스펙: specs/03-visual-rules.md

## 맥락

원본 영상 프레임 분석에서 두 종류의 텍스트가 발견됐다. (a) 치수선 옆 "재식계획(1황)", "조각역상(7분)" 같은 **깨진 한국어** — 이미지 생성 모델이 그린 것이라는 증거. (b) 하단 자막과 대형 숫자(280개, 49일, 97개) — SRT와 정확히 일치하거나 깨끗함 → 후처리 합성 추정. 즉 원본 제작자도 "분위기용 텍스트는 생성, 정확해야 하는 텍스트는 합성"으로 운영 중일 가능성이 높다.

## 결정

- **레이어 A (생성)**: 측정선·낙서풍 어노테이션 등 분위기 요소는 이미지 프롬프트에 포함해 생성한다. 텍스트 정확도를 검증하지 않으며 깨진 글자를 허용한다.
- **레이어 B (합성)**: 자막, 대형 강조 숫자, 장소명 라벨, 파티클 등 시청자가 읽어야 하는 모든 텍스트는 FFmpeg(ASS/drawtext) 후처리로 합성한다.

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| 전부 이미지 생성에 포함 | 파이프라인 단순 | 한국어 렌더링 불안정, 오타 시 씬 재생성 비용 | 신뢰성 |
| 전부 후처리 합성 | 정확성 | 이미지에 자연스럽게 녹아드는 낙서풍 질감 상실 | 원본 룩과 괴리 |

## 결과

- overlay 단계(파이프라인 8)와 assemble 단계(9)에 합성 책임 집중
- 레이어 B용 폰트/스타일 에셋을 코드 리포지토리에 포함 (재현성)
- 되돌릴 조건: 이미지 모델의 한국어 정확도가 유의미하게 개선되어 오타율 < 5%가 되면 레이어 B 일부의 생성 이관 재검토
