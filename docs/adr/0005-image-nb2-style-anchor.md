# ADR-0005: 이미지 생성은 Nano Banana 2 + 스타일 앵커 레퍼런스 방식을 사용한다

- 상태: 승인
- 날짜: 2026-08-07
- 관련 스펙: specs/03-visual-rules.md, specs/05-pipeline.md

## 맥락

편당 30~40씬에서 동일한 photoreal 3D 디오라마 룩을 유지해야 하며, 정확한 텍스트는 레이어 B(후처리)가 담당하므로(ADR-0002) 텍스트 렌더링 정확도는 선정 기준에서 제외된다. 핵심 기준: (1) 스타일 일관성 메커니즘(레퍼런스 이미지), (2) 편집(2-pass 어노테이션) 능력, (3) Kling i2v 입력 화질, (4) 비용. Midjourney는 공식 API 부재로 자동화 불가 → 탈락.

## 결정

- 기본 모델: **Nano Banana 2** (멀티 레퍼런스 일관성 + 편집 능력 + 단가, Pro 대비 ~95% 품질에 1/3 수준 비용)
- 스타일 일관성: 승인된 **스타일 앵커 이미지 3~5장**을 리포지토리 에셋(`assets/style_anchors/`)으로 관리하고 모든 생성 호출에 레퍼런스로 첨부. 앵커 변경은 스펙 03 수정으로 취급
- 어노테이션(레이어 A): 클린 베이스 생성 → 편집 2-pass로 추가. 단, Ken Burns 씬에만 적용 (Kling 씬은 ADR-0006)
- 해상도: 2K (최종 출력 1080×1920 + Kling 입력에 충분, 4K 금지)
- 비용 산정: 편당 ~50호출(재시도·2-pass 포함) ≈ $2~2.5. NB Pro 전환 시 ~$6.7
- 히어로 씬(hook_fact 첫 컷) NB Pro 사용 여부는 A/B 청취·시청 비교 후 결정 (보류)

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| Nano Banana Pro 전면 사용 | 최상 화질, 4K | 편당 $10, 폰 세로 시청에서 차이 체감 낮음 | 실험 반복 비용 과다 |
| FLUX 2 Pro | 저가, 레퍼런스 8장 | 편집 워크플로우 열위 | 2-pass 어노테이션 요구 |
| Seedream 4.5/5.0 | 최저가 | 일관성 제어 수단 약함 | 채널 룩 유지가 핵심 |
| Midjourney | 미학 최상 | 공식 API 없음 | 자동화 불가 |

## 결과

- 스타일 앵커가 코드 리포지토리의 버전 관리 대상이 됨 (룩 변경 이력 추적 가능)
- 되돌릴 조건: 스타일 앵커 방식으로도 씬 간 룩 편차가 시청 가능 수준을 벗어나면 FLUX 2(레퍼런스 8장) 재평가. 화질 불만 반복 시 히어로 씬부터 Pro 단계 도입
