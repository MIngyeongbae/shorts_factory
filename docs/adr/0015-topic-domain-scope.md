# ADR-0015: 소재 도메인을 한국 문화기술사 + 건축·토목으로 고정한다

- 상태: 대체됨(→ ADR-0016 → **ADR-0033**). 2026-08-13에 도메인 제한 자체가 없어졌다
- 날짜: 2026-08-10
- 관련 스펙: specs/00-overview.md, specs/06-topic-research.md

> **대체 사유**: 발굴을 실제로 돌려보니 한국 한정이 레퍼런스 채널과 계속 겹쳤고, 1차 사료
> 필수 조건과 결합해 소재 풀이 지나치게 좁았다. 도메인의 **포함/제외 갈래 기준은 그대로**
> 유효하고(문제 해결 서사가 있는가), 국가 제한만 풀렸다. ADR-0016 참고.

## 맥락

파이프라인은 지금까지 도메인 중립으로 만들어졌다. 건축이 실제로 박힌 곳은
`prompts/01-research.md` 첫 줄 하나뿐이고, 소재 4조건·비트 스키마·시각 룰·단계 구조는
어느 도메인에나 적용된다. 그래서 도메인을 정하지 않아도 코드는 돈다. 문제는 **소재 발굴이
시작되지 않는다**는 것이다 — 검색 범위와 사료 우선순위가 도메인에 달려 있다.

도메인 후보를 고를 때 기준은 하나다. **스펙 01의 7단 구조가 문제 해결 서사**라는 것.

```
문제 성립 → 쉬운 해법 실패 → 두 번째 해법도 실패 → 발상 전환 → 해결 + 숫자 → 현존
```

이 틀은 "이 물건을 왜 이렇게 만들었는가"에 답이 있는 소재에서만 채워진다. 실패 기록과
구체적 숫자가 사료로 남아야 4조건의 2번·3번이 성립하기 때문이다.

건축·토목만으로 좁히면 위험이 하나 남는다. 레퍼런스로 삼은 "신비한 건축사전"과 정면으로
겹친다 — 실제로 첫 토픽(한양도성 각자성석)이 그 채널 기존 영상과 같은 소재라 `[0b]`에서
반려됐다. 반대로 문화 전반으로 넓히면 예술 양식·사상·세시풍속이 들어와 4조건이 무너진다.

## 결정

**한국 문화기술사 + 건축·토목**으로 고정한다.

- **포함**: 공예·생산 기술(도자·한지·옻칠·금속활자), 저장·보존 기술(장·김치·석빙고·사고),
  인쇄·기록, 측정·역법, 그리고 성곽·궁궐·치수·도시계획
- **제외**: 예술 양식·미의식·사상, 세시풍속·놀이·음악. 실패한 대안의 사료도 구체적 숫자도
  없어 7단 구조를 채우지 못한다

두 갈래를 합치는 이유는 **경계 소재가 오히려 품질이 좋기** 때문이다. 석빙고는 건축이자
저장 기술이고, 가마는 구조물이자 공예이며, 사고(史庫)는 건축이자 기록 보존이다. 둘로 갈라
놓으면 이런 소재를 어느 쪽으로 보낼지 매번 다투게 된다.

다른 도메인(과학사 일반, 해외 유적, 일본판)은 이 리포지터리를 넓혀서 담지 않는다. 기능이
확정된 뒤 분기하거나 도메인 팩을 얹는다.

## 검토한 대안

| 대안 | 장점 | 단점 | 탈락 사유 |
|---|---|---|---|
| 건축·토목 단독 | 스펙 01·03 실측 기반과 정확히 일치 | 레퍼런스 채널과 정면 중복 | 각자성석 반려가 실증 |
| 문화 전반 | 소재 풀 최대 | 예술·사상·풍속은 4조건 2·3번 불성립 | `[0b]`에서 대량 반려 |
| 문화기술사 단독 | 중복 위험 없음 | 석빙고·가마·사고 같은 경계 소재를 버리게 됨 | 가장 좋은 소재가 경계에 있다 |
| 지금 도메인 팩 추상화 | 나중 확장 용이 | 무엇이 도메인 의존인지 아직 모른다 | 한 편도 안 만든 상태의 추측 설계 |

## 결과

- 스펙 00에 "소재 도메인" 절, 스펙 06에 도메인 전제를 명시
- `prompts/01-research.md`의 조사원 역할과 학술 소스 예시를 두 갈래로 확장
- **도메인은 4조건과 나란한 다섯 번째 조건이 아니다.** 백로그 진입 전에 걸러지는 전제이므로
  팩트시트 `conditions`(4키)는 그대로다 — 스키마·검증기·픽스처가 변하지 않는다
- **중복 위험 구간이 남는다.** 건축·토목 쪽은 레퍼런스 채널과 겹칠 수 있다. `[0b]`의 비판
  세션이 이미 중복을 판정하지만(각자성석 사례), 발굴 단계에서 한 번 더 거르는 쪽이 싸다
- 시각 룰(스펙 03)은 건축 3편 실측이라 편향이 있다. "드론 뷰/광각 전경"과 "조감 디오라마"는
  가마·활자 주조에 잘 맞지 않는다. 반대로 "단면 컷"은 더 잘 맞는다. 첫 편을 만든 뒤
  룰 테이블을 보정한다 — 지금 미리 고치지 않는다
- 되돌릴 조건: 4조건(특히 "실패한 대안의 기록")을 만족하는 소재가 고갈되면 도메인 확장이
  아니라 **분기 시점**이 온 것으로 본다
