# 레퍼런스 분석: 신비한 건축사전 3편 실측

분석 대상: 백악(101.6s), 한양도성 각자성석(93.4s), 춘당지(92.1s). 원본 mp4 + ko.srt.

## 대본 실측
- 글자 수(공백·부호 제외): 545 / 552 / 572자
- 문장(자막 줄) 수: 28 / 23 / 26
- TTS 속도: 5.4 / 5.9 / 6.2자/초
- 자막 1줄 평균: 3.6 / 4.0 / 3.5초
- 시그니처 문구 실측 위치: "그래서 발상을 뒤집습니다" = 44.0s / 50.0s / 44.5s

## 영상 실측
- 9:16, 30fps, h264+aac (수집본은 360p/202p 저화질 다운로드본)
- scene>0.15 전환: 43 / 35 / 35회 → 이미지 전환 약 2.3~2.9초당 1회
- scene>0.3 (하드컷 성격): 12 / 9 / 18회 → 전환 다수가 디졸브
- 오디오: mean -16.5 / -15.1 / -16.7dB, 피크 0dB

## 텍스트 레이어 증거
- 깨진 한국어 어노테이션 발견: "재식계획(1황)", "조각역상(7분)", "떨김" → 이미지 생성 모델이 그린 텍스트
- 하단 자막은 SRT와 정확 일치 → 후처리 번인
- 대형 빨간 숫자(280개/49일/97개/18.6km)는 깨끗함 → 합성 추정
→ ADR-0002 (2계층 전략)의 근거

## 반복 연출 패턴
- 실패/부정 비트마다 빨간 크레용 X (3편 공통 스타일)
- 숫자 비트마다 대형 빨간 텍스트 + 치수선
- 해결 비트에서 단면(cross-section) 컷 사용
- 전 프레임 우하단 반짝이 파티클(✦)
- "발상을 뒤집습니다" 시점 오디오 컷+차임 (외부 분석 보고서 + 청취 확인)
