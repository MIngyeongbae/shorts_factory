# 검증 보고서: 스펙 01 대본 규칙 검증기

- 일자: 2026-08-09
- 대상: `src/shorts_factory/schemas/script_rules.py` (`validate_script`)
- 기준 데이터: 레퍼런스 채널 "신비한 건축사전" 3편의 원본 SRT (`신비한 건축사전 대본/`)
- 관련: specs/01-script-template.md, ADR-0013

## 검증 질문

정정된 스펙 01(ADR-0013 반영)이 **실제로 성공한 대본 3편을 통과시키는가.**

이 질문이 중요한 이유는 스펙 01의 수치가 원래 이 3편에서 역산된 것이기 때문이다. 검증기가
원본을 떨어뜨리면 스펙이 틀린 것이지 대본이 틀린 게 아니다.

## 방법

1. 3편의 SRT를 파싱해 자막 큐 단위로 분해 (ADR-0013: 씬 1개 = 자막 줄 1개)
2. 백악 편은 비트를 태깅해 `tests/fixtures/scenes_golden_baegak.json`으로 고정 → 검증기 전 항목 실행
3. 나머지 2편은 비트 없이 판정 가능한 항목(2·3·5)과, `solution` 구간을 시점(54~85초)으로
   근사한 항목(4)을 측정

## 검증 중 발견한 스펙 오류

### 반올림값을 경계로 쓴 탓에 원본이 자기 기준에서 탈락했다

첫 실행에서 골든 픽스처(백악)가 경고 2건을 냈다.

```
발화 속도 5.40자/초 (권장 5.4~6.2자/초)
scenes/9: 0.88초 (줄당 0.9~6.8초)
```

원인은 `reference-analysis.md`의 반올림 표기(5.4자/초)를 그대로 경계로 옮긴 것이다. 실제 값은
545자 ÷ 101.0초 = **5.396**자/초이고, 9번 줄("쌓인다고요?")은 **0.875초**다. 둘 다 경계 바로
아래였다.

스펙 01의 범위를 3편을 모두 포함하는 엔벨로프로 넓혔다.

| | 수정 전 | 수정 후 | 실측 엔벨로프 |
|---|---|---|---|
| 발화 속도 | 5.4~6.2자/초 | **5.3~6.3자/초** | 5.396~6.217 |
| 줄당 시간 | 0.9~6.8초 | **0.8~6.9초** | 0.875~6.76 |

## 한계 (이 보고서가 증명하지 않는 것)

- **검증 1항목은 1편에서만 측정했다.** 비트 태깅은 사람 판단이고 그 판단을 한 사람이 검증기도
  썼다. 픽스처를 3편으로 늘려도 같은 판단이 3번 반복될 뿐이라 검증력이 늘지 않는다. 이 항목은
  실제 생성기가 뱉은 대본을 태깅 없이 받아볼 때 처음으로 진짜 시험대에 오른다.
- **항목 2·3과 분량 규칙만이 판단 무관하다.** SRT의 타임스탬프와 글자 수에서 바로 나오므로
  이 보고서에서 가장 신뢰할 수 있는 부분이다.
- **수미상관(5항목)은 형태소 분석기 없는 휴리스틱이다.** 조사를 떼고 용언·불용어를 걸러 명사
  후보를 뽑는다. 3편 모두 의미 있는 공유어를 잡았지만, 무의미한 어절 하나만 겹쳐도 통과한다.
  차단 기준이 아니라 바닥선으로 두는 게 맞다 — 품질 판정은 `[2b. judge]`가 한다.
- **`solution` 구간 근사.** 각자성석·춘당지는 비트가 없어 54~85초 시점으로 잘랐다. 백악 편은
  비트 기준과 시점 기준이 같은 결과(3개)를 냈다.

## 재현

원본 SRT는 남의 저작물이라 저장소에 없다. 원본 대본 전문을 담은 골든 픽스처도 마찬가지로
`.gitignore` 대상이다. 로컬에 SRT를 두고 픽스처를 생성한 뒤 테스트를 돌린다.

```bash
python tools/srt_to_scenes.py          # 신비한 건축사전 대본/*.srt → tests/fixtures/
python -m pytest tests/test_script_rules.py -q
```

SRT가 없으면 골든 픽스처를 쓰는 테스트 15건은 skip되고, 픽스처와 무관한 6건
(`noun_stems`·`core_chars` 유닛, 스키마 픽스처 대조)만 돈다.

`tools/srt_to_scenes.py`에서 사람 판단이 들어간 것은 `beat`·`subject`·`emphasis`·`motion`
테이블뿐이다. `camera`는 스펙 03의 비트별 기본값을 그대로 쓰고, 텍스트와 타임스탬프는
SRT에서 1:1로 옮긴다.
