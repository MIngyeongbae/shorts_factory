### ADR-0027 (승인·구현 완료) — 방언 축

`[5]`에 `--dialect {mj,nb2}`, 기본값 `mj`. 한 실행에 방언 하나만 내고 `style.dialect`에
적는다. `[6]`은 자기 프로바이더와 어긋나면 **호출 전에** 멈춘다(`DialectMismatch`,
종료 코드 12) — 방언이 틀린 문자열은 편당 과금을 쓴 뒤에야 실패하기 때문이다.

MJ 방언 = 한 줄 콤마 나열 + `--ar 9:16` + `--no 항목, 항목`. 앵커 없음(ADR-0025 G3).
**`[6]`이 보내는 것은 `prompt` + 공백 + `negative_prompt`다** — 이 조합이 탐침에서 통한
그 문자열이고, `test_the_shipped_string_matches_what_was_verified`가 못 박고 있다.

구현하며 판단 둘을 더 했다.

- **MJ 방언에서 앵커 없음 경고를 끈다.** G3이 MJ 경로의 앵커를 폐기했는데 경고만 남아 있었다
- **`--dialect`가 다르면 완료된 단계도 다시 쓴다.** 안 그러면 `--dialect nb2`를 줬는데
  아무 일도 안 일어난 것처럼 보인다. 재생성은 무료다

**옛 `prompts.json`은 `style.dialect`가 없어 스키마 위반이다.** 마이그레이션 단계는
만들지 않았다 — `[5]`를 다시 돌리면 된다.

`officialFastRemaining`이 `54000 → 53520 → 53040`으로 **정확히 480씩** 줄었다.
"영상 1잡 = 8 GPU분"이 카운터로 확정 → **월 11.2편 상한**도 확정.
Fast/Relax는 별도 풀이고 `relax_credits`는 음수로 내려간다(사용량 기록).

### 삽질 4건 — 다음 세션이 다시 밟지 않도록

1. **Windows 단독 실행 파일이 안 돈다.** v11.10.4·v11.10.3 둘 다 난독화 모듈
   이니셜라이저에서 `Marshal.GetDelegateForFunctionPointer` 널로 크래시. 보안SW 차단
   아님(ASR 없음·Defender 0건·.NET 설치됨). **Docker로만 돌린다**
2. **Redis가 필수다** — `EnableRedis=False`인데 `CounterHelper`가 무조건 호출해서
   계정·사용자·홈 API가 전부 500. **UI 계정 화면이 실제로 죽어 있었다.** 별도 컨테이너 연결
3. **`EnableOfficial=False`가 기본값**이라 "공식 계정 추가" 버튼이 아예 안 보인다.
   `EnableSwagger`도 켜면 `/swagger`에서 전체 스키마를 읽을 수 있다 — 이게 제일 빨랐다
4. **MJ CDN이 Cloudflare 403이다**(컨테이너 안에서도). `ImageStorageType=LOCAL` +
   `LocalStorage.customCdn`을 설정해야 `localhost:8086/attachments/...`로 나온다.
   **동작 조건이지 최적화가 아니다**

### 인증 계약 — 여기서 제일 오래 막혔다

`isOfficial` 계정은 **`userToken` 하나만** 쓴다(`cookie` 필드는 UI에 없다). 그리고:

- **액세스 토큰 값만 넣으면 401이다.** `이름=값; 이름=값` **쿠키 문자열 전체**를 넣어야 한다.
  프록시가 이 값을 `Cookie:` 헤더에 그대로 넣기 때문
- **액세스 토큰 수명은 60분**(JWT `exp`−`iat`=3600). DevTools의 쿠키 만료일(30일)은
  그릇의 것이지 JWT의 것이 아니다
- **리프레시 토큰(`..._r`)을 같이 넣는 것이 핵심.** 만료 2분 뒤에도 인증이 통과했고
  브라우저 컨텍스트 초기화가 5,699ms → 636ms로 떨어졌다
- **자동 갱신 확정 (13:02 재확인).** 만료 **86분** 후에도 통과했고, **컨테이너 재시작
  후에도** 통과했다(5,633ms — 컨텍스트 재초기화). DB에는 만료된 액세스 토큰이 그대로인데
  거기서 부팅해 붙었으므로 **리프레시 토큰만으로 부트스트랩한다**. 갱신본은 메모리에만
  있지만 DB에 리프레시 토큰이 있어 재부팅이 안전하다. **`[0] token` 수확 단계는 불필요**
- `loginAccount`/`loginPassword` 자동 로그인은 **쓸 수 없다.** `login2fa`(TOTP 시드)가
  필수인데 휴대폰 2FA 사용자는 시드가 없고, 그 경로는 Discord 계정용이다

### 계약 공백 — 1건 해결, 1건 미결, 1건 신규

### `knowledge/`를 토픽 폴더로 (ADR-0026) — 마이그레이션 완료

사람이 "폴더 구분이 없어 지저분하다"고 판단 → **ADR-0012의 되돌릴 조건이 발동했다.**
ADR-0012가 요구한 대로 **축적된 49장의 분포를 먼저 측정**하고 축을 골랐다:

- `topics`: 피사 **27** / 후버댐 **22** = 49. **모든 카드가 한 토픽에만 속한다** —
  토픽 간 재사용(ADR-0012의 존재 이유)이 **아직 0회**다. 토픽이 2개뿐이라 그렇다
- `subjects`: 고유값 10개 중 **3개가 1회만 등장** → 1장짜리 폴더가 생긴다. 게다가
  슬러그 규칙이 없는 자유 문자열이라 **표기가 흔들리면 그게 새 폴더가 된다.** 그래서 탈락

**핵심은 폴더를 계약이 아니라 표시 규약으로 둔 것이다:**

| | |
|---|---|
| 배치 | 최초 조사 토픽 (`topics[0]`) |
| **이동** | **안 한다** — 인용 토픽이 늘어도 파일은 제자리 |
| 진실 | `topics:` frontmatter. **코드는 경로를 파싱하지 않는다** |
| 조회 | `find_card()` 재귀 탐색 — 폴더를 몰라도 되고 평면 배치도 읽힌다 |

덕분에 **`index.md`에서는 걸치는 소스가 소속된 모든 섹션에 등장한다.** 파일은 한 곳에만
있을 수 있지만 표의 줄은 그렇지 않다. 섹션 순서는 카드 수 내림차순 → 슬러그 사전순.

- `card_path` 하나를 **`find_card`(조회) + `placement_path`(배치)** 로 나눴다
- **`injection()`의 표 잘라내기 기준을 첫 `|` → 첫 `## `로 바꿨다.** 안 그러면 첫 섹션
  제목이 잘려 세션 프롬프트에서 어느 토픽의 표인지 알 수 없다 — 섹션 도입이 만든 버그다
- 49장 `git mv` 완료(전부 `R`로 인식). **다토픽 카드가 0장이라 배치에 판단이 개입 안 했다**

### `format=gbrp` — 실측이 아니었으면 못 잡았을 것

**zoompan은 크롭 원점을 크로마 정렬에 맞춰 버린다** (`px = (int)x & ~(chroma_w-1)`).
yuv420이면 그 정렬이 2픽셀이라, 초당 1.2픽셀로 가는 느린 팬에서 **창이 몇 프레임씩
멈췄다가 2픽셀을 뛴다.**

탐침 116프레임 `pan_right`의 프레임 간 차이가 `0.02 → 14.2 → 0.02`로 진동했다 —
**40%의 프레임이 완전한 정지다.**

| zoompan 입력 포맷 | 프레임차 변동계수 | 클립당 |
|---|---|---|
| yuv420 (기본) | **81.2%** | 3.5초 |
| **gbrp (채택)** | **22.9%** | 3.9초 |
| gbrp + 2배 업스케일 | 16.2% | 5.2초 |

크로마 서브샘플링이 없으면 정렬이 1픽셀이 되어 정지 프레임이 사라진다. 2배 업스케일은
+49%를 쓰고 얻는 것이 적다. 펜선·작도선이 많은 ADR-0023 룩에서 11%는 싸다.
**`test_kenburns.py`가 `format=gbrp`의 위치까지 못박는다** — 눈으로만 보이는 회귀다.

### `[9]`가 첫 실물 실행에서 깨졌다 (고침)

```
First input link main timebase (1/1000000) do not match
the corresponding second input link xfade timebase (1/30)
```

**`concat`이 출력 타임베이스를 `AV_TIME_BASE`로 바꾼다.** 그래서 하드컷 **뒤에 오는

### ADR-0021 — Nano Banana 2 호출 경로 (승인·구현 완료)

**Nano Banana 2 = Gemini 이미지 모델이다.** `gemini-3.1-flash-image`,
`POST /v1beta/interactions`, 헤더 `x-goog-api-key`.

- **SDK를 쓰지 않는다.** `google-genai`는 `pydantic`·`google-auth`·`httpx`를 끌고 오는데
  우리가 쓰는 엔드포인트는 하나다. ADR-0008이 LLM 쪽에서 같은 선택을 이미 했다.
  대신 HTTP 경계를 `transport` 하나로 좁혔다 (`[9]`의 `run_ffmpeg`와 같은 모양)
- **계약값이 API 파라미터와 문자열까지 같다** — `prompts.json`의 `9:16`·`2K`가 그대로 나간다
- **실호출로 드러난 것 3가지**
  - **PNG를 못 받는다.** `image/png`은 400이다 (`Supported values: 'image/jpeg'`).
    → 산출물이 **`images/{scene_id}.jpg`**가 됐다. 변환해 봐야 손실은 이미 일어난 뒤라
    화질이 안 돌아오고 의존성만 는다. 확장자는 프로바이더가 정한다(`output_suffix`) —
    페이크는 stdlib로 만들 수 있는 PNG를 낸다
  - **응답에 `output_image` 편의 필드가 없다.** 이미지는 `steps[].content[]`로만 온다.
    두 경로를 다 읽도록 만들어 둬서 그대로 통과했다
  - 남은 미확인은 **레이트리밋(429) 응답 형태**뿐이다
- **비용 재산정**: 2K **$0.101/장** → 후버 27씬 $2.73 / 피사 25씬 $2.53. ADR-0005 갱신
- **앵커 상한이 3장이다** (오브젝트 10 + 캐릭터 4 + **스타일 3**). ADR-0005의 "3~5장"을 3장으로 고쳤다

### ADR-0023 — 베이스 스타일 교체 (승인·구현 완료)

`photorealistic 3D 디오라마` → **펜선·수채 위의 극사실 건축 렌더링.**
사람이 레퍼런스 14장을 줬고 공통점을 뽑았다. **"색연필"이라 불렀지만 실제 기법은
펜선 + 투명 수채였다** — 프롬프트 문구가 결과를 가르므로 이 구분이 중요했다.

- 앵커 3장 확정 (`assets/style_anchors/`, 5.2MB, **커밋 대상**). 손글씨 4장·야경 2장은 뺐다
- **비율을 두 번 잡았다.** 1차(수채 우세)는 재질이 뭉개졌고, `realism dominant over
  painterly looseness`를 넣은 2차에서 골재·나뭇결·암반 층리가 살아났다. 사람이 2차를 택했다
- **자막색을 뒤집었다** — 흰 종이에 흰 글자는 외곽선만 남는다. `검정 + 흰 외곽선 3px`
- 네거티브에 **"읽을 수 있는 글자·손글씨 낙서 금지"** 추가. 실호출 6장 전부 글자가 없었다
- **구도 토큰 21개는 그대로 살았다.** 카메라 프레이밍이지 렌더 스타일이 아니다
- **하단 1/3이 저절로 비워진다.** 원래 여백으로 끝내는 기법이라 자막 영역이 공짜로 나온다

### ADR-0022 — `visual_goal` 신설, 씬 계약 5필드 (승인·구현 완료)

**여기가 이번 세션에서 제일 큰 변화다.** 사람이 정한 원칙:

> 글로 짧은 시간에 설명하는 건 한계가 있다. **그림도 설명의 일종으로 쓴다.**
> 시간 채우기식 그림은 퀄리티로 느껴지지 않는다. 분량은 고정이고 **그 안의 밀도를 올린다.**

- **탐침이 문제를 드러냈다.** 피사 1번이 아무 이탈리아 탑으로 나왔다. `subject`가
  "이탈리아 도시 광장의 오래된 벽돌 종탑"이라 특정하지 않았기 때문이다.
  반면 후버 27번은 `subject`에 **이름을 박아서** 실제 후버댐이 나왔다 —
  **모델은 이름을 대면 실물을 그린다.** 능력 문제가 아니라 지시 문제였다
- 52씬을 재 보니 **본문과 그림이 어긋나는 씬들이 있었다** (피사 1: "무너집니다"인데 멀쩡한 탑,
  피사 2: "잔해 8,000 m³"인데 텅 빈 광장, 후버 14: 인부가 서 있는 분위기 컷)
- **`[1]`이 하는 일의 순서가 바뀐다.** 팩트시트를 읽고 *글이 나은가 / 그림이 나은가 /
  둘 다인가*를 **먼저 가른 뒤** 텍스트와 씬 목표를 함께 쓴다. 텍스트를 다 쓰고 나서
  피사체를 붙이지 않는다
- **`[1b] score`의 루브릭에 이미 `info_density`가 있었다.** 채점 축은 있는데 밀도를
  올리는 수단이 설계에 없었던 것이다
- **검증 두 겹**: 비면 `[1]`이 실패 / **`text`와 70% 이상 겹치면 계약 위반**
  (문자 바이그램. 한국어라 형태소 분석기 없이 재려면 이게 가장 단순하다)
- **`scenes.timed.json`에는 안 싣는다.** `[7]`·`[9]`는 그림이 뭘 설명하는지 알 필요가 없다
  (ADR-0020). `timed_scenes.py`에 `DROPPED`를 뒀다
- **`[5]`가 프롬프트에 싣는다** — `This image must explain (...)`. 피사체만 주면 모델은
  그것을 그릴 뿐이고 왜 거기 있는지는 모른다
