    - `low` = 소수설·출처 불명 → 사용 금지 (현행 유지)
  - 소스 등급 A(기관·학술·1차 사료) / B(**위키백과 포함**) / C(언론·해설) / D(나무위키·블로그, 근거 불가)

  - 해외 소재는 한국어 자료가 얕아 **영어 검색을 프롬프트에서 지시**한다
  - "확정 안 됐다"는 이유로 `low`로 내리지 말라고 검증 프롬프트에 명시했다.
    로마 콘크리트·피라미드 운반처럼 훅이 센 소재가 `medium`에 몰려 있다
- **주의**
  - **추정 표현 규칙은 기계 검증이 아니다.** 프롬프트 지시일 뿐이고 그라운딩 검증기는
    여전히 숫자만 대조한다. 지켜졌는지는 `[2b. judge]` 몫 — 아직 미구현이다
  - ADR-0016의 되돌릴 조건: 단정 서술이 반복되면 `medium`을 `low`와 동일 취급(대본 제외)으로 후퇴
  - 백로그의 기존 후보 3건(갑인자·석빙고·실록 사고)은 **옛 규칙(1차 사료)으로 고른 것**이다.
