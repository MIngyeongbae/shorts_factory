### ADR-0018 — 구도는 `(beat × subject_scale)`로 결정한다 (승인·반영 완료)

- **택일 3행과 구도-피사체 충돌 9씬이 같은 공백이었다.** 스펙이 "전경 유지 **or**
  클로즈업"이라 적어 둔 것은 "피사체에 따라 다르다"는 말인데, 그 "피사체에 따라"를
  계약이 표현할 수단이 없었다. 구도를 정하려면 비트만으로 모자라고 **피사체 스케일**이 필요하다
- 씬 계약에 `subject_scale`(`wide`|`close`|`diagram`) 추가. **`[1]`이 쓴다** —
  연출이 아니라 피사체 서술이라 `subject`와 같은 자리다 (ADR-0014를 네 필드로 갱신)
- 스펙 03 구도 열 → **12행 × 3열 표**. 구도 토큰 21개로 정리
- **`@prev`/`@hook`은 스케일이 같을 때만 잇는다.** 다르면 스케일별 기본값으로 떨어진다.
  후버댐 2번 씬이 정확히 이 경우다 (1번 diagram → 2번 wide). 안 막았으면 단면 구도를
  전경에 쓴다. 사람이 "수미상관은 꼭 지킬 필요 없다"고 정해서 `ending_echo`도 같은 규칙
- 충돌 9씬이 전부 풀렸다. 후버댐 1번: `drone_wide` → `subject_closeup`

### ADR-0019 — 레이어 A 어노테이션 전부 폐기 (승인·반영 완료)

- **사람 판단이 시작점이다** — "빨간 크레용은 원본 채널 걸 분석하다 들어간 것이라
  없어도 된다". 물어보니 X 계열만이 아니라 **빨간 어노테이션 전체**를 버리기로 했다
- 스펙 03 오버레이 6종 삭제(크레용 X·X 대형·측정선·라벨 박스·치수선/화살표·장소명 라벨).
  남은 것은 레이어 B 둘 — `big_red_text`, `sparkle_particles`
- **편당 이미지 호출이 절반 가까이 준다.** 2-pass 대상이 후버댐 27씬 중 14, 피사 25씬 중 12였다.
  호출 41 → 27 / 37 → 25. ADR-0005의 "편당 ~50호출 ≈ $2~2.5"는 재산정 대상으로 적어 뒀다
- **나머지 공백 3건이 덤으로 사라졌다** — `turning_point`의 "X → 사라짐"(정지 이미지에
  못 담는 스펙 오류), 라벨 박스·장소명 라벨의 **문구 출처 부재**
- **오버레이 타입 enum 표를 드디어 만들었다.** 스펙 02가 "스펙 03의 enum"이라 참조만 하고
  실체가 없던 것이다. `schemas/scenes.py`의 `emphasis.type`이 문자열 → enum이 됐다

### ADR-0020 — 2부 내부 계약 3파일, 값의 출처는 하나 (승인·반영 완료)

- 계약을 적다가 **실물 대조로 중복을 찾았다** — `timing.json`의 `cues`가
  `scenes.timed.json`의 **완전 부분집합**이고 후버댐 27씬 값도 전부 같았다
- 없앨 수 있는지 확인했다. `cues`의 유일한 예정 소비자 `[9]`는 **어차피
  `scenes.timed.json`을 읽어야 한다** — 스펙 03 전환 규칙이 비트에 걸려 있고
  (`turning_point` 진입 시 컷, 하드컷은 `hook_twist`·`dilemma_peak`만) `beat`은
  `timing.json`에 없다. → **`cues` 제거**
- 파일 3개에 겹치지 않는 역할을 줬다
  - `scenes.timed.json` = **씬의 유일한 출처** (대본 속성 + 실측 시각) → `[7]`·`[9]`
  - `prompts.json` = 씬별 이미지 지시, **시간 없음** → `[6]`·`[8]`
  - `timing.json` = **`[3]`의 실행 기록** (엔진·배속·경고) → `[11]`·사람.
    계약이 아니라 기록이라 **길이 초과로 멈출 때도 남는다** (편당 과금 증거)
- **`[3]`과 `[5]`는 선후가 없다.** 둘 다 `06-script.json`만 읽는다. 스펙 05 그림이
  순서가 있는 것처럼 그려져 있었다. **TTS 키가 없는 지금 `[5] → [6]`까지 갈 수 있다**
- `prompts.json`은 지금 모양 그대로 동결. 계약 문구 3개를 스펙 05에 박았다 —
  `subject` 번역 금지, **`framing_reuse_of`는 이미지 재사용이 아님**(구도만 같다),
  씬당 호출 1회
- `camera`/`motion` 중복은 **사람이 남기기로 했다.** Ken Burns 구도가 카메라 워크와
  무관하지 않아서다 (`pan_right`면 오른쪽에 볼 것이 있어야 한다). 고치는 곳은
  `06-script.json` 하나라고 못 박았다

### ADR-0017 — 1부↔2부 경계를 읽기 전용으로 동결 (승인·반영 완료)

- 막고 있던 것은 **스펙 자체**였다. specs/02는 `est_start/est_end`가 "TTS 후 갱신"이라 했고
  specs/05는 `[3]`이 "scenes.json 갱신"이라 했다. **2부 첫 단계가 1부 산출물을 제자리에서 고쳐 쓰는
